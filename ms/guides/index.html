Laman Utama / Panduan

Panduan cara guna untuk Android dan Windows

Jawapan langkah demi langkah untuk soalan harian: sejarah papan keratan, nota dan pemasa di atas apl lain, buka apl secara automatik selepas but semula, bunyi lebih kuat, sembunyikan maklumat peribadi dalam tangkapan skrin dan banyak lagi.

Android

Untuk telefon & tablet · Google Play

  • Cara melihat sejarah papan keratan di AndroidClipboard+
  • Cara membuka aplikasi secara automatik selepas but semula di Android (tanpa root)AutoStart+
  • Cara mengekalkan nota di atas aplikasi lain di AndroidFloatNote+
  • Cara mengekalkan pemasa pada skrin semasa menggunakan aplikasi lain di AndroidFloatTimer+
  • Cara menyembunyikan maklumat peribadi dalam tangkapan skrin sebelum berkongsiPhotoCleaner+
  • Pembaris bacaan untuk disleksia dan ADHD di Android: jangan hilang baris semasa membacaReadFocus+
  • Cara menggunakan kalkulator di atas aplikasi lain di AndroidFloatCalc+
  • Cara melihat harga kripto semasa menggunakan aplikasi lain di AndroidFloatCrypto+
  • Cara menjadikan bunyi telefon Android lebih kuatVolumeBooster+

Windows

Untuk PC Windows · Microsoft Store

  • Cara mengekalkan nota melekat sentiasa di atas di WindowsFloatNote+ for Windows
  • Cara melihat sejarah papan keratan di WindowsClipboard+ for Windows
  • Cara mengekalkan pemasa di atas tetingkap lain di WindowsFloatTimer+ for Windows
  • Cara menggunakan pembaris bacaan di Windows (untuk disleksia dan ADHD)ReadFocus+ for Windows
  • Cara menyembunyikan maklumat peribadi dalam tangkapan skrin dan PDF di WindowsPhotoCleaner+ for Windows
  • Cara mengekalkan ticker kripto langsung di atas tetingkap lain di WindowsFloatCrypto+ for Windows
