Як користуватися лінійкою для читання у Windows (при дислексії та СДУГ)

Оновлено 2026-10-14

Під час читання довгих сторінок на моніторі рядок легко загубити. Лінійка для читання підсвічує рядок, на якому ви зараз, або затемнює решту екрана, щоб погляд не збивався.

Спосіб 1: «Line focus» у Microsoft Edge

У Microsoft Edge є «Immersive Reader» — режим чистого читання вебсторінок. У його налаштуваннях читання функція «Line focus» підсвічує один, три або п'ять рядків за раз. Вона працює лише на сторінках, відкритих в Immersive Reader, але не в PDF, документах чи інших застосунках.

Спосіб 2: смуга фокуса поверх будь-якого застосунку

ReadFocus+ for Windows (наш застосунок) кладе смугу фокуса поверх усього, що ви читаєте: вебсторінки, PDF, документа, коду. «Маска» затемнює верх і низ екрана й лишає світлу смугу; «Підсвічування» позначає рядок, на якому ви зараз. Смуга пропускає кліки наскрізь, тож ви прокручуєте й клацаєте під нею як раніше.

  1. Установіть ReadFocus+ із Microsoft Store.
  2. Запустіть його з плаваючої панелі або сполученням клавіш і виберіть «Маску» чи «Підсвічування».
  3. Перемістіть смугу на свій рядок або зсувайте її вгору й униз сполученнями клавіш під час читання.
  4. З панелі можна зафіксувати смугу, приховати її або перенести на інший монітор.

Безкоштовно і Pro

Безкоштовна версія містить обидва режими й три теми, сеансами до 60 хвилин. Pro — разова покупка: знімає обмеження часу й додає преміум-теми, налаштування висоти та непрозорості смуги і «Не вимикати екран». Реклами немає.

ReadFocus+ for Windows

Смуга фокуса для Windows, крізь яку проходять кліки — Маска та Підсвічування тримають погляд на рядку.

Відкрити у Microsoft Store → Про застосунок

Запитання

Чи є у Windows лінійка для читання?

В Immersive Reader браузера Edge є Line focus для вебсторінок. Для інших застосунків — PDF, Word, редакторів коду — потрібне екранне накладання, наприклад ReadFocus+ for Windows.

Чи не перехоплюватиме смуга мої кліки?

Ні. ReadFocus+ for Windows пропускає кліки наскрізь: прокручування, виділення й клацання потрапляють до застосунку під смугою.
