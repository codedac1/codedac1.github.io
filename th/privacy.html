สรุปโดยย่อ

  • ไม่ต้องสมัครสมาชิก และ CodeDAC ไม่ได้ดำเนินการเซิร์ฟเวอร์ใดๆ ที่รับหรือจัดเก็บข้อมูลของคุณ ข้อยกเว้นเดียวคือบันทึกการซื้อที่แอป Windows ส่งเมื่อการซื้อ PRO เสร็จสมบูรณ์ (ข้อ 6)
  • โดยค่าเริ่มต้น ข้อมูลแอปจะถูกจัดเก็บไว้บนอุปกรณ์ของคุณเท่านั้น
  • การสำรองข้อมูลและการซิงค์กับ Google Drive ใน Clipboard+ และ FloatNote+ เป็นทางเลือก และจะบันทึกไว้ใน Drive ของคุณเองเท่านั้น
  • โฆษณาในแอป Android ของเราแสดงโดย Google AdMob และจะขอความยินยอมก่อนในพื้นที่ที่กำหนดให้ต้องขอความยินยอม แอป Windows ของเราไม่มีโฆษณา
  • สอบถาม: contact@codedac.com

1. หลักการสำคัญ

คุณสามารถใช้แอปได้โดยไม่ต้องสร้างบัญชีหรือลงชื่อเข้าใช้ เราไม่ได้ดำเนินการเซิร์ฟเวอร์ใดๆ ที่รับหรือจัดเก็บข้อมูลของคุณ และโดยค่าเริ่มต้น ข้อมูลที่แอปจัดการจะถูกจัดเก็บและประมวลผลบนอุปกรณ์ของคุณ ข้อยกเว้นมีเพียงฟีเจอร์ทางเลือกที่คุณเปิดใช้เอง (ข้อ 3) และบริการภายนอกที่แอปใช้งาน (ข้อ 4–6) ซึ่งอธิบายไว้ทั้งหมดด้านล่าง กรณีเดียวที่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ของเราคือบันทึกการซื้อจากแอป Windows (ข้อ 6)

2. ข้อมูลที่ประมวลผลบนอุปกรณ์ของคุณ

  • ข้อมูลที่แอปจำเป็นต้องใช้ในการทำงาน (ประวัติคลิปบอร์ด โน้ต ตัวจับเวลา การตั้งค่า เป็นต้น) จะถูกจัดเก็บไว้บนอุปกรณ์ของคุณเท่านั้น และไม่ถูกส่งมายังเรา
  • PhotoCleaner+ (Android) ค้นหาและซ่อนข้อมูลส่วนบุคคลในรูปภาพและไฟล์ PDF (การจดจำข้อความ ใบหน้า และบาร์โค้ด) บนอุปกรณ์ของคุณ โดยใช้โมเดล Google ML Kit ที่ติดตั้งมาในแอป รูปภาพและเอกสารจะไม่ถูกอัปโหลดเลย
  • PhotoCleaner+ for Windows ทำงานแบบเดียวกันบนพีซีของคุณ โดยใช้การจดจำข้อความและใบหน้าที่มีอยู่ใน Windows และตัวอ่านบาร์โค้ดที่มาพร้อมกับแอป รูปภาพ ไฟล์ PDF และภาพที่วางจะไม่ถูกอัปโหลดเลย สำเนาที่บันทึกจะถูกเข้ารหัสใหม่จากพิกเซล จึงไม่มีข้อมูลเมตาของไฟล์ต้นฉบับ (ตำแหน่ง เวลาที่ถ่าย หรือข้อมูลอุปกรณ์) แอปไม่เก็บรายการไฟล์ที่คุณเปิด และไฟล์ชั่วคราวสำหรับการแชร์และการพิมพ์จะถูกลบเมื่อเปิดและปิดแอป คำที่คุณเลือกให้ซ่อนเสมอจะถูกจัดเก็บไว้ในการตั้งค่าแอปบนพีซีของคุณเท่านั้น
  • การถอนการติดตั้งแอปจะลบข้อมูลแอปที่จัดเก็บไว้บนอุปกรณ์ของคุณด้วย

3. ฟีเจอร์ทางเลือก: การสำรองข้อมูลและการซิงค์กับ Google Drive

Clipboard+ (Android และ Windows) และ FloatNote+ (Android และ Windows) มีฟีเจอร์ Google Drive เพื่อให้คุณย้ายข้อมูลระหว่างอุปกรณ์ได้ ฟีเจอร์เหล่านี้ปิดไว้ตามค่าเริ่มต้น และฟีเจอร์อื่นๆ ทั้งหมดใช้งานได้โดยไม่ต้องเปิดใช้

  • การลงชื่อเข้าใช้ Google. แอปจะขอให้คุณลงชื่อเข้าใช้ด้วยบัญชี Google ก็ต่อเมื่อคุณเปิดใช้ฟีเจอร์เท่านั้น เพื่อวัตถุประสงค์เดียวคือการเข้าถึง Google Drive ของคุณเอง
  • ข้อมูลของคุณไปที่ใด. เมื่อเปิดการซิงค์ Clipboard+ จะบันทึกรายการที่คุณคัดลอก และ FloatNote+ จะบันทึกโน้ตของคุณ ไว้ในพื้นที่ส่วนตัวเฉพาะแอปใน Google Drive ของคุณเอง (โฟลเดอร์ที่ซ่อนอยู่ appDataFolder) ข้อมูลจะไปยังบัญชี Google ของคุณเท่านั้น — และจะไม่ถูกส่งไปยัง CodeDAC เลย
  • การเข้าถึงที่จำกัด. การซิงค์ใช้เฉพาะขอบเขต drive.appdata ซึ่งมองเห็นได้เฉพาะไฟล์ที่แอปสร้างขึ้นในพื้นที่ที่ซ่อนอยู่นั้น ฟีเจอร์สำรองข้อมูลของ Clipboard+ สำหรับ Android ยังใช้ขอบเขต drive.file ด้วย ซึ่งเข้าถึงได้เฉพาะไฟล์สำรองข้อมูลที่แอปสร้างขึ้นเองเช่นกัน ทั้งสองขอบเขตไม่สามารถเข้าถึงส่วนที่เหลือใน Google Drive ของคุณได้
  • รูปภาพ. รูปภาพที่คุณแนบไว้ในโน้ตของ FloatNote+ จะยังคงอยู่ในอุปกรณ์ของคุณ สิ่งที่ไปพร้อมกับโน้ตมีเพียงการอ้างอิงถึงชื่อไฟล์เท่านั้น
  • การหยุดใช้และการลบ. คุณสามารถปิดฟีเจอร์เหล่านี้หรือออกจากระบบได้ทุกเมื่อ การลบข้อมูลแอปหรือไฟล์สำรองข้อมูลที่จัดเก็บไว้ใน Google Drive ของคุณ จะเป็นการลบสำเนาที่ซิงค์และสำรองไว้

4. ข้อมูลที่รับส่งผ่านอินเทอร์เน็ต

บางฟีเจอร์ดึงข้อมูลจากอินเทอร์เน็ต คำขอเหล่านี้ไม่มีข้อมูลใดที่ระบุตัวตนของคุณ แต่เช่นเดียวกับคำขอทางอินเทอร์เน็ตทุกรายการ เซิร์ฟเวอร์ปลายทางจะได้รับที่อยู่ IP ของอุปกรณ์ของคุณ

  • อัตราแลกเปลี่ยนใน FloatCalc+. เมื่อคุณแปลงสกุลเงิน แอปจะดึงอัตราแลกเปลี่ยนจาก API อัตราแลกเปลี่ยนสาธารณะ (Frankfurter)
  • ราคาใน FloatCrypto+. ราคาและกราฟของคริปโตเคอร์เรนซีดึงมาจาก API สาธารณะ (CoinGecko, Binance)
  • ML Kit ใน PhotoCleaner+ (Android). การจดจำภาพเกิดขึ้นบนอุปกรณ์ของคุณ แต่ Google ML Kit อาจส่งข้อมูลการวินิจฉัยไปยัง Google ได้แก่ ข้อมูลอุปกรณ์ (ผู้ผลิต รุ่น เวอร์ชันระบบปฏิบัติการ) ข้อมูลแอป และตัวชี้วัดประสิทธิภาพและข้อผิดพลาด เพื่อปรับปรุงบริการและแก้ไขปัญหา ทั้งนี้ไม่รวมรูปภาพของคุณและเนื้อหาที่จดจำได้
  • Microsoft Store ในแอป Windows ของเรา. แอป Windows สื่อสารกับ Microsoft Store เพื่อตรวจสอบสิทธิ์การใช้งาน PRO และการซื้อของคุณ

5. โฆษณาและความยินยอมด้านโฆษณา

แอป Android แบบฟรีของเราแสดงโฆษณาจาก Google AdMob แอป Windows ของเราไม่มีโฆษณา

  • ข้อมูลที่เก็บรวบรวม. AdMob อาจเก็บรวบรวมรหัสโฆษณาของคุณ ตำแหน่งโดยประมาณที่อนุมานจากที่อยู่ IP และข้อมูลอุปกรณ์และการใช้งานแอป เพื่อแสดงและวัดผลโฆษณา รวมถึงป้องกันการฉ้อโกง ด้วยเหตุนี้ แอปจึงมีสิทธิ์ที่ SDK โฆษณาจำเป็นต้องใช้ (อินเทอร์เน็ต สถานะเครือข่าย รหัสโฆษณา) และในบางแอปยังมีการเข้าถึง API โฆษณาของ Android (Privacy Sandbox) ด้วย วิธีที่ Google ใช้ข้อมูลโฆษณา
  • ความยินยอมด้านโฆษณา. ในพื้นที่ที่กำหนดให้ต้องขอความยินยอม เช่น เขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ แอปจะถามตัวเลือกของคุณเกี่ยวกับโฆษณาแบบเฉพาะบุคคลผ่านหน้าจอขอความยินยอมของ Google (User Messaging Platform) เมื่อคุณเปิดแอปเป็นครั้งแรก แอปส่วนใหญ่ให้คุณเปลี่ยนตัวเลือกได้จากเมนูความยินยอมด้านโฆษณา (ตัวเลือกความเป็นส่วนตัว) ภายในแอป และไม่ว่าแอปใด การล้างข้อมูลของแอปจะทำให้แอปถามอีกครั้งเมื่อเปิดใช้ครั้งถัดไป
  • การปิดโฆษณาแบบเฉพาะบุคคล. ไม่ว่าคุณจะอยู่ที่ใด คุณสามารถลบหรือรีเซ็ตรหัสโฆษณา หรือปิดการปรับโฆษณาให้เหมาะกับคุณ ได้ในการตั้งค่าอุปกรณ์
  • การนำโฆษณาออก. การซื้อ PRO จะนำโฆษณาออก

6. การชำระเงิน

  • Android. การซื้อ PRO ดำเนินการโดย Google Play Billing
  • Windows. การซื้อ PRO ดำเนินการโดย Microsoft Store

สโตร์แต่ละแห่งเป็นผู้ดำเนินการชำระเงิน เราไม่เคยได้รับหมายเลขบัตรหรือรายละเอียดการชำระเงินอื่นๆ ของคุณ แอปได้รับจากสโตร์เฉพาะสถานะการซื้อที่จำเป็นต่อการตรวจสอบสิทธิ์การใช้ PRO ของคุณเท่านั้น

บันทึกการซื้อจากแอป Windows เมื่อการซื้อ PRO ใน PhotoCleaner+, ReadFocus+ หรือ FloatTimer+ สำหรับ Windows เสร็จสมบูรณ์ แอปจะส่งบันทึกสั้นๆ ไปยังเซิร์ฟเวอร์ของ CodeDAC (โฮสต์บน Google Cloud) ได้แก่ รหัสผลิตภัณฑ์ ราคาและสกุลเงินที่สโตร์แสดง การตั้งค่าประเทศ/ภูมิภาคของ Windows เวอร์ชันของแอป และหมายเลขสุ่มที่สร้างขึ้นสำหรับการติดตั้งนั้น บันทึกนี้ไม่มีชื่อ ที่อยู่อีเมล บัญชี Microsoft หรือข้อมูลอุปกรณ์ เราใช้บันทึกนี้เพื่อนับยอดขายและป้องกันไม่ให้นับการซื้อเดียวกันซ้ำเท่านั้น โดยจัดเก็บหมายเลขสุ่มไว้เฉพาะในรูปแบบที่แปลงแล้วซึ่งย้อนกลับไม่ได้ (แฮช) เช่นเดียวกับคำขอทางอินเทอร์เน็ตทั่วไป เซิร์ฟเวอร์จะได้รับที่อยู่ IP ของคุณ และบันทึกการเข้าถึงเซิร์ฟเวอร์จะถูกลบโดยอัตโนมัติหลังจาก 30 วัน

7. สิทธิ์การเข้าถึง

แต่ละแอปขอเฉพาะสิทธิ์ที่จำเป็นต่อฟีเจอร์ของตนเท่านั้น และใช้เพื่อวัตถุประสงค์ที่ระบุไว้เท่านั้น สิทธิ์ที่แต่ละแอปขอแสดงไว้ในสิ่งที่แต่ละแอปเชื่อมต่อด้านบน

  • แสดงทับแอปอื่น — แสดงเครื่องคิดเลขลอย ตัวจับเวลา โน้ต ราคา เครื่องมือช่วยอ่าน หรือแผงคลิปบอร์ดไว้บนหน้าจอ
  • การแจ้งเตือน — แสดงสถานะของฟีเจอร์ที่กำลังทำงานและการแจ้งเตือนต่างๆ (ตัวจับเวลาหมดเวลา การแจ้งเตือนราคา เป็นต้น)
  • ทำงานต่อเนื่อง (บริการเบื้องหน้า) — ทำให้ฟีเจอร์ต่างๆ เช่น หน้าต่างลอยหรือการเพิ่มระดับเสียง ยังคงทำงานหลังจากคุณออกจากแอป
  • เริ่มทำงานเมื่อเปิดเครื่อง — เริ่มแอปหรือฟีเจอร์ที่คุณตั้งค่าไว้อีกครั้งเมื่อเปิดอุปกรณ์
  • ไม่ใช้การเพิ่มประสิทธิภาพแบตเตอรี่ — ป้องกันไม่ให้ระบบบล็อกการเปิดแอปอัตโนมัติเมื่อเปิดเครื่อง (AutoStart+)
  • เปลี่ยนการตั้งค่าเสียง — ใช้การเพิ่มระดับเสียงและอีควอไลเซอร์ (VolumeBooster+)
  • รหัสโฆษณา — ใช้เพื่อแสดงโฆษณา (ข้อ 5)

สิทธิ์พื้นฐาน เช่น อินเทอร์เน็ต สถานะเครือข่าย และการสั่น จะได้รับอนุญาตโดยอัตโนมัติเมื่อติดตั้ง และใช้เฉพาะสำหรับฟีเจอร์ข้างต้นเท่านั้น แอปไม่ขอสิทธิ์ไมโครโฟน รายชื่อติดต่อ ตำแหน่ง กล้อง หรือพื้นที่เก็บข้อมูล

8. เว็บไซต์ (codedac.com)

เว็บไซต์ของเราใช้ Google Analytics เพื่อวัดการเข้าชม สำหรับผู้เข้าชมในเขตเศรษฐกิจยุโรป สหราชอาณาจักร และสวิตเซอร์แลนด์ โหมดความยินยอม (Consent Mode) จะตั้งค่าเริ่มต้นเป็น “ปฏิเสธ” จึงไม่มีการจัดเก็บคุกกี้วิเคราะห์ และส่งเฉพาะสัญญาณเชิงสรุปแบบไม่ระบุตัวตนเท่านั้น ส่วนในพื้นที่อื่นจะใช้คุกกี้วิเคราะห์เพื่อวัดการเข้าชม ไม่ว่ากรณีใด เราไม่เก็บรวบรวมตัวระบุสำหรับโฆษณา และเว็บไซต์ไม่มีการแสดงโฆษณา นโยบายความเป็นส่วนตัวของ Google

คุณสามารถเลือกไม่รับการวิเคราะห์ได้โดยบล็อกคุกกี้ในเบราว์เซอร์ หรือติดตั้งส่วนเสริมเบราว์เซอร์สำหรับเลือกไม่ใช้ Google Analytics เว็บไซต์ใช้พื้นที่จัดเก็บในเครื่องของเบราว์เซอร์ (localStorage) เพื่อจดจำภาษาและธีม (โหมดมืด) ที่คุณเลือก ค่าเหล่านี้จะไม่ถูกส่งไปยังเซิร์ฟเวอร์เลย

9. อีเมลที่คุณส่งถึงเรา

หากคุณส่งอีเมลถึงเรา เราจะได้รับที่อยู่อีเมลของคุณและสิ่งที่คุณเขียน (รวมถึงรายละเอียดอุปกรณ์หรือแอปที่คุณใส่มา) เราใช้ข้อมูลนี้เพื่อตอบกลับคุณและดำเนินการตามคำขอของคุณเท่านั้น และเก็บรักษาไว้เพียงเท่าที่จำเป็นสำหรับวัตถุประสงค์ดังกล่าว

10. ความเป็นส่วนตัวของเด็ก

สำหรับแอปที่มุ่งเน้นเด็ก เราปฏิบัติตามนโยบายครอบครัวของ Google Play และกฎหมายที่เกี่ยวข้อง ในบริบทที่มุ่งเน้นเด็ก เราไม่ใช้โฆษณาแบบเฉพาะบุคคล และไม่จงใจเก็บรวบรวมข้อมูลส่วนบุคคลจากเด็ก

11. การเปลี่ยนแปลงนโยบายนี้

เราอาจปรับปรุงนโยบายนี้เพื่อสะท้อนการเปลี่ยนแปลงทางกฎหมายหรือการเปลี่ยนแปลงของแอป เมื่อมีการปรับปรุง เราจะอัปเดตวันที่อัปเดตล่าสุดในหน้านี้และประวัติการเปลี่ยนแปลงด้านล่าง
