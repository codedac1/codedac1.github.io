วิธีปิดข้อมูลส่วนตัวในภาพหน้าจอและ PDF บน Windows

อัปเดต 2026-10-14

ภาพหน้าจอและเอกสารสแกนมักมีเบอร์โทรศัพท์ อีเมล เลขบัตรหรือเลขประจำตัว ที่อยู่ หรือใบหน้า ก่อนส่งหรือโพสต์จากพีซี ให้ปิดข้อมูลเหล่านั้นจนกู้คืนไม่ได้

ทางเลือกที่ 1: Snipping Tool

Snipping Tool เวอร์ชันล่าสุดบน Windows 11 ซ่อนอีเมลและเบอร์โทรศัพท์ในภาพหน้าจอได้ผ่าน “Text actions” และคุณวาดทับสิ่งอื่นได้เอง อย่าใช้ปากกาไฮไลต์สำหรับงานนี้ เพราะมันโปร่งแสง ให้ใช้เส้นทึบที่ปิดแต่ละรายการได้มิด

ทางเลือกที่ 2: PhotoCleaner+ for Windows

PhotoCleaner+ for Windows (แอปของเรา) ค้นหาส่วนที่น่าจะเป็นข้อมูลส่วนตัวในรูปภาพ ภาพหน้าจอ และ PDF เช่น เบอร์โทรศัพท์ อีเมล เลขบัตร IBAN เลขหนังสือเดินทาง ชื่อ ที่อยู่ ป้ายทะเบียนรถ ใบหน้า และ QR โค้ด แล้วส่งออกสำเนาที่ปิดด้วยมาสก์ทึบ ทุกอย่างทำงานบนพีซีของคุณ ไม่มีการอัปโหลดใด ๆ

  1. เปิดไฟล์ วางด้วย Ctrl+V ลากมาวางในหน้าต่าง หรือคลิกขวาที่ไฟล์ใน File Explorer แล้วเลือก “Clean with PhotoCleaner+”
  2. ตรวจกล่อง คลิกเพื่อเปิดหรือปิด ลากเพื่อย้ายหรือปรับขนาด และวาดกล่องเองทับส่วนที่ตกหล่น
  3. ส่งออกสำเนาที่ปิดแล้ว จะบันทึก คัดลอก แชร์ หรือบันทึกเป็น PDF ก็ได้ ต้นฉบับจะไม่ถูกเขียนทับ และสำเนาที่บันทึกไม่มีเมทาดาทา

ฟรีและ Pro

การค้นหาข้อมูลส่วนตัวใช้ฟรีไม่จำกัด และส่งออกได้ฟรีวันละ 3 เอกสาร Pro เป็นการซื้อครั้งเดียวที่ยกเลิกขีดจำกัดรายวัน และเพิ่มการส่งออก PDF และการพิมพ์ ไม่มีโฆษณาและไม่มีลายน้ำ

แอปในคู่มือนี้

PhotoCleaner+ for Windows

ซ่อนข้อมูลส่วนตัวในรูปภาพ ภาพหน้าจอ และ PDF บน PC ของคุณก่อนแชร์

ดูบน Microsoft Store → รายละเอียดแอป

คำถามที่พบบ่อย

แอปจะพบข้อมูลส่วนตัวทุกจุดไหม?

ไม่มีเครื่องมือใดสัญญาได้ การตรวจจับเป็นเพียงจุดเริ่มต้น ตรวจกล่องทุกครั้งก่อนส่งออก และวาดทับส่วนที่ตกหล่นด้วยตัวเอง

ไฟล์ของฉันถูกอัปโหลดไหม?

ไม่ การตรวจจับ การปิดบัง และการส่งออกทำงานบนพีซีของคุณ ไม่ต้องมีบัญชีและไม่มีการอัปโหลดใด ๆ
