วิธีให้โน้ตกาวอยู่บนสุดเสมอบน Windows

อัปเดต 2026-10-14

โน้ตกาวจะมีประโยชน์ก็ต่อเมื่อคุณมองเห็นมัน บน Windows โน้ตบนเดสก์ท็อปมักไปอยู่หลังเบราว์เซอร์ เอกสาร หรือสเปรดชีตที่คุณกำลังใช้ จนต้องคุ้ยหา มีสองวิธีที่จะให้โน้ตอยู่บนสุด

ทางเลือกที่ 1: ปักหน้าต่างด้วย PowerToys

Microsoft PowerToys ชุดเครื่องมือฟรีจาก Microsoft มีเครื่องมือ “Always On Top” ติดตั้ง PowerToys เปิด “Always On Top” คลิกหน้าต่างที่ต้องการให้อยู่ด้านหน้า เช่น หน้าต่างโน้ต แล้วกด Win+Ctrl+T กดอีกครั้งเพื่อเลิกปัก

วิธีนี้ใช้ได้กับเกือบทุกหน้าต่าง แต่หน้าต่างที่ปักไว้ก็ยังเป็นหน้าต่างเต็มรูปแบบ มันจะแย่งโฟกัสเมื่อคุณคลิก และกินพื้นที่เท่าเดิมไม่ว่าคุณจะกำลังอ่านโน้ตอยู่หรือไม่

ทางเลือกที่ 2: โน้ตที่ออกแบบมาให้ลอยอยู่แล้ว

FloatNote+ for Windows (แอปของเรา) ให้โน้ตแต่ละใบอยู่เป็นชิปเล็ก ๆ เหนือทุกหน้าต่าง คลิกชิปแล้วมันจะขยายเป็นการ์ดตรงนั้น กด Esc ก็ย่อกลับ ชิปไม่เคยแย่งโฟกัสจากแอปด้านหลัง เคอร์เซอร์จึงอยู่ตรงที่คุณพิมพ์ค้างไว้

  1. ติดตั้ง FloatNote+ จาก Microsoft Store
  2. สร้างโน้ตจากไอคอนในถาดระบบหรือด้วยปุ่มลัดทั่วระบบ โน้ตจะปรากฏเหนือหน้าจอเป็นการ์ด
  3. ทำงานต่อได้เลย โน้ตจะอยู่เหนือทุกหน้าต่าง คลิกลูกศรด้านบนหรือกด Esc เพื่อย่อเป็นชิป
  4. ลากชิปไปไว้ที่ไหนก็ได้ ใช้สีและข้อความจัดรูปแบบเพื่อแยกแต่ละใบ และตั้งการเตือนให้โน้ตขึ้นมาในเวลาที่กำหนด

โน้ตของคุณอยู่บนมือถือด้วย

FloatNote+ for Windows ซิงก์กับแอป FloatNote+ บน Android ผ่าน Google Drive ของคุณเอง โน้ตที่เขียนบนพีซีจึงไปอยู่บนมือถือด้วย ทุกฟีเจอร์ของเวอร์ชัน Windows ใช้ฟรี

แอปในคู่มือนี้

FloatNote+ for Windows

โน้ตกาวที่ลอยอยู่เหนือทุกหน้าต่างบน Windows และซิงค์กับแอป FloatNote+ บน Android

ดูบน Microsoft Store → รายละเอียดแอป

คำถามที่พบบ่อย

Sticky Notes ของ Windows อยู่เหนือหน้าต่างอื่นได้ไหม?

ในการตั้งค่าส่วนใหญ่ ตัวมันเองทำไม่ได้ คุณสามารถปักหน้าต่างใดก็ได้ รวมถึงหน้าต่างโน้ต ด้วย “Always On Top” ของ PowerToys (Win+Ctrl+T) หรือใช้แอปที่โน้ตออกแบบมาให้ลอยเหนือหน้าต่างอื่นอยู่แล้ว

โน้ตลอยจะแย่งโฟกัสจากสิ่งที่ฉันกำลังพิมพ์ไหม?

ชิปของ FloatNote+ ไม่แย่ง การคลิกหรือลากชิปจะไม่ทำให้เคอร์เซอร์หลุดจากแอปที่คุณใช้อยู่ มีเพียงการ์ดที่เปิดอยู่เท่านั้นที่รับโฟกัส เพราะคุณต้องพิมพ์ลงไปในนั้น
