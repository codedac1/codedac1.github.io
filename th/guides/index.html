หน้าแรก / คู่มือ

คู่มือการใช้งาน Android และ Windows

คำตอบทีละขั้นตอนสำหรับคำถามที่พบบ่อย: ดูประวัติคลิปบอร์ด ลอยโน้ตและตัวจับเวลาไว้เหนือแอปอื่น เปิดแอปอัตโนมัติหลังรีสตาร์ท เพิ่มเสียงให้ดังขึ้น ซ่อนข้อมูลส่วนตัวในภาพหน้าจอ และอื่น ๆ

Android

สำหรับมือถือและแท็บเล็ต · Google Play

  • วิธีดูประวัติคลิปบอร์ดบน AndroidClipboard+
  • วิธีเปิดแอปอัตโนมัติหลังรีสตาร์ท Android (ไม่ต้องรูท)AutoStart+
  • วิธีให้โน้ตลอยอยู่เหนือแอปอื่นบน AndroidFloatNote+
  • วิธีให้ตัวจับเวลาอยู่บนหน้าจอขณะใช้แอปอื่นบน AndroidFloatTimer+
  • วิธีปิดข้อมูลส่วนตัวในภาพหน้าจอก่อนแชร์PhotoCleaner+
  • ไม้บรรทัดช่วยอ่านสำหรับดิสเล็กเซียและ ADHD บน Android: อ่านได้ไม่หลุดบรรทัดReadFocus+
  • วิธีใช้เครื่องคิดเลขลอยเหนือแอปอื่นบน AndroidFloatCalc+
  • วิธีดูราคาคริปโตขณะใช้แอปอื่นบน AndroidFloatCrypto+
  • วิธีทำให้มือถือ Android เสียงดังขึ้นVolumeBooster+

Windows

สำหรับพีซี Windows · Microsoft Store

  • วิธีให้โน้ตกาวอยู่บนสุดเสมอบน WindowsFloatNote+ for Windows
  • วิธีดูประวัติคลิปบอร์ดบน WindowsClipboard+ for Windows
  • วิธีให้ตัวจับเวลาอยู่เหนือหน้าต่างอื่นบน WindowsFloatTimer+ for Windows
  • วิธีใช้ไม้บรรทัดช่วยอ่านบน Windows (สำหรับดิสเล็กเซียและ ADHD)ReadFocus+ for Windows
  • วิธีปิดข้อมูลส่วนตัวในภาพหน้าจอและ PDF บน WindowsPhotoCleaner+ for Windows
  • วิธีให้แถบราคาคริปโตแบบเรียลไทม์อยู่เหนือหน้าต่างอื่นบน WindowsFloatCrypto+ for Windows
