วิธีดูประวัติคลิปบอร์ดบน Windows

อัปเดต 2026-10-14

พอคัดลอกอันใหม่ คลิปก่อนหน้าก็หายไป เว้นแต่คุณจะเก็บประวัติไว้ Windows 10 และ 11 มีฟีเจอร์นี้ในตัว และแอปจัดการคลิปบอร์ดเก็บได้นานกว่านั้น

ทางเลือกที่ 1: ประวัติคลิปบอร์ดในตัว (Win+V)

กด Win+V ครั้งแรก Windows จะถามให้เปิดประวัติคลิปบอร์ด (หรือเปิดได้ใน “Settings > System > Clipboard”) หลังจากนั้น Win+V จะแสดงคลิปล่าสุด และคลิกที่คลิปก็จะวางทันที

ใช้งานได้รวดเร็ว แต่มีข้อจำกัด เก็บได้สูงสุด 25 รายการ และทุกอย่างยกเว้นรายการที่ปักหมุดจะถูกล้างเมื่อรีสตาร์ทพีซี ไม่มีการค้นหา และส่งไปถึงมือถือไม่ได้

ทางเลือกที่ 2: แอปจัดการคลิปบอร์ดที่เก็บทุกอย่างไว้

Clipboard+ for Windows (แอปของเรา) อยู่ในถาดระบบ และบันทึกข้อความกับรูปภาพทันทีที่คุณคัดลอก ประวัติจะอยู่จนกว่าคุณจะลบ และคุณค้นหา จัดเป็นกลุ่มและสนิปเป็ต และเรียกขึ้นมาด้วยปุ่มลัดได้

  1. ติดตั้ง Clipboard+ จาก Microsoft Store แอปจะเริ่มทำงานในถาดระบบ
  2. คัดลอกตามปกติ คลิปข้อความและรูปภาพทุกรายการจะถูกบันทึกอัตโนมัติ
  3. กดปุ่มลัดส่วนกลางเพื่อเปิดหน้าต่างเลือกด่วนที่ตำแหน่งเคอร์เซอร์ เลือกคลิปด้วย Ctrl+1–9 แล้วกด Enter เพื่อวาง
  4. เปิดหน้าต่างหลักเพื่อค้นหา ปักหมุด แก้ไข หรือเก็บข้อความที่ใช้บ่อยไว้เป็นสนิปเป็ต

ระหว่างมือถือกับพีซี

เมื่อใช้คู่กับแอป Clipboard+ บน Android สิ่งที่คุณคัดลอกบนมือถือจะวางบนพีซีได้ และในทางกลับกัน ผ่าน Google Drive ของคุณเอง ประวัติคลิปบอร์ด สนิปเป็ต กลุ่ม การค้นหา และหน้าต่างเลือกด่วนใช้ฟรี ส่วน Pro เพิ่มการซิงก์ พื้นที่เก็บรูปภาพไม่จำกัด และการส่งออก PDF

ดูบน Microsoft Store → รายละเอียดแอป

คำถามที่พบบ่อย

ทำไมประวัติคลิปบอร์ด Win+V ว่างเปล่าหลังรีสตาร์ท?

Windows ล้างประวัติคลิปบอร์ดเมื่อรีสตาร์ทพีซี ยกเว้นรายการที่ปักหมุด แอปจัดการคลิปบอร์ดอย่าง Clipboard+ จะเก็บประวัติของคุณไว้แม้รีสตาร์ท

ประวัติคลิปบอร์ดของ Windows เก็บได้กี่รายการ?

สูงสุด 25 รายการ รายการเก่าจะหลุดออกไปเมื่อคุณคัดลอกรายการใหม่
