หน้าแรก / FloatTimer+ for Windows / คู่มือ

วิธีให้ตัวจับเวลาอยู่เหนือหน้าต่างอื่นบน Windows

อัปเดต 2026-10-14

การจับเวลาการนำเสนอ ช่วงโฟกัส หรือการโทร จะง่ายขึ้นเมื่อเวลาอยู่ในสายตาตลอด Windows มีวิธีในตัวอยู่หนึ่งวิธี และแอปตัวจับเวลาแบบลอยทำได้มากกว่านั้น

ทางเลือกที่ 1: “Keep on top” ในแอป Clock

แอป Clock ที่มาพร้อม Windows แสดงตัวจับเวลาในหน้าต่างเล็กที่อยู่เหนือหน้าต่างอื่นได้ โดยเริ่มตัวจับเวลา ขยายมัน แล้วเลือก “Keep on top” ใช้ได้กับตัวจับเวลาเดียว และแสดงในหน้าต่างเล็กขนาดคงที่

ทางเลือกที่ 2: การ์ดตัวจับเวลาแบบลอย

FloatTimer+ for Windows (แอปของเรา) ทำให้ตัวจับเวลา ตัวนับ และนาฬิกาจับเวลาลอยเหนือทุกหน้าต่างเป็นการ์ดพาสเทลใบเล็ก การ์ดไม่เคยรับโฟกัส การคลิกการ์ดจึงไม่ทำให้เคอร์เซอร์หลุดจากตรงที่คุณพิมพ์อยู่

  1. ติดตั้ง FloatTimer+ จาก Microsoft Store แอปจะอยู่ในถาดระบบ
  2. สร้างตัวจับเวลา ตัวนับ หรือนาฬิกาจับเวลา แล้วทำให้มันลอย
  3. เริ่ม หยุดชั่วคราว และรีเซ็ตได้จากตัวการ์ดเอง ลากไปไว้ที่ไหนก็ได้หรือปรับขนาดได้
  4. พับเก็บเป็นฟองเล็ก ๆ หรือดันไปชิดขอบจอ เมื่ออยากได้พื้นที่คืน

ฟรีและ Pro

คุณสร้างตัวจับเวลา ตัวนับ และนาฬิกาจับเวลาได้มากเท่าที่ต้องการ และไม่มีโฆษณา เวอร์ชันฟรีให้การ์ดลอยได้ครั้งละหนึ่งใบ ส่วน Pro เป็นการซื้อครั้งเดียว ให้ลอยได้มากเท่าที่ต้องการ และเพิ่มตัวจับเวลาแบบวนซ้ำและการแจ้งเตือนที่กำหนดเองได้

แอปในคู่มือนี้

FloatTimer+ for Windows

ตัวจับเวลา ตัวนับ และนาฬิกาจับเวลาที่ลอยอยู่เหนือทุกหน้าต่างบน Windows เป็นการ์ดพาสเทลใบเล็ก

ดูบน Microsoft Store → รายละเอียดแอป

คำถามที่พบบ่อย

Windows มีตัวจับเวลาที่อยู่บนสุดเสมอไหม?

“Keep on top” ของแอป Clock แสดงตัวจับเวลาหนึ่งตัวในหน้าต่างเล็กเหนือหน้าต่างอื่น ถ้าต้องการใช้ตัวจับเวลา ตัวนับ หรือนาฬิกาจับเวลาหลายตัวพร้อมกัน ให้ใช้แอปตัวจับเวลาแบบลอย

ตัวจับเวลาแบบลอยจะเกะกะการทำงานไหม?

การ์ดของ FloatTimer+ ไม่เคยแย่งโฟกัสจากแอปด้านล่าง และคุณพับเก็บเป็นฟองหรือซุกไว้ที่ขอบจอได้
