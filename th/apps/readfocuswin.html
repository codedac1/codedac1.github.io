ReadFocus+ for Windows

ตัวช่วยอ่านบน Windows ที่อยู่ในถาดระบบ: มาสก์การอ่านหรือไฮไลต์บรรทัดช่วยตรึงสายตาไว้กับบรรทัด ส่วนการคลิกจะทะลุลงไปยังแอปด้านล่างตามปกติ

ดูบน Microsoft Store → ติดต่อเรา

ภาพรวม

ReadFocus+ for Windows คือเวอร์ชันเดสก์ท็อปของแอป ReadFocus+ บน Android โดยจะวางแถบช่วยอ่านแบบเรียบ ๆ ทับสิ่งที่คุณกำลังอ่าน ไม่ว่าจะเป็นหน้าเว็บ PDF เอกสาร หรือโค้ด เพื่อให้ไม่หลุดบรรทัด มาสก์การอ่านจะหรี่ส่วนบนและล่างของหน้าจอลงอย่างนุ่มนวลและเหลือแถบสว่างไว้ตรงกลาง ส่วนไฮไลต์บรรทัดจะทำเครื่องหมายบรรทัดที่กำลังอ่านด้วยแถบสีอ่อน แถบช่วยอ่านนี้คลิกทะลุได้ คุณจึงเลื่อน เลือก และคลิกแอปด้านล่างได้เหมือนเดิม และแผงลอยขนาดเล็กก็ใช้สลับโหมด ย้ายหรือล็อกแถบ และซ่อนแถบได้โดยไม่ต้องออกจากสิ่งที่กำลังอ่าน

มีให้ใช้งานบน Android ด้วย

ReadFocus+ ตัวช่วยอ่านสำหรับผู้มีภาวะดิสเล็กเซียและ ADHD ด้วยไฮไลต์บรรทัดและมาสก์ ›

ฟีเจอร์เด่น

  • สองโหมดการอ่าน — มาสก์การอ่านหรี่ทุกอย่างนอกแถบสว่าง ส่วนไฮไลต์บรรทัดทำเครื่องหมายบรรทัดที่กำลังอ่าน
  • คลิกทะลุ: เลื่อน เลือก และคลิกแอปด้านล่างได้เหมือนเดิม ไม่มีอะไรมาขวางเมาส์
  • แผงลอยสำหรับสลับโหมด ย้ายหรือล็อกแถบ และซ่อนแถบ พับเหลือแถวเดียวได้เมื่อไม่ต้องใช้
  • แป้นพิมพ์ลัดสำหรับเริ่มและหยุด สลับโหมด แสดงและซ่อน ล็อก และเลื่อนแถบขึ้นลง
  • รองรับหลายจอ: แถบการอ่านจะตามแผงควบคุมไปยังจอที่คุณย้ายไป และเวลาที่เหลือจะพักอยู่ในถาดระบบ
  • ไม่มีโฆษณา Pro เป็นการซื้อครั้งเดียว: ธีมพรีเมียม การตั้งค่าแถบโฟกัส ป้องกันหน้าจอดับ และไม่จำกัดเวลา

ภาพหน้าจอ

แตะที่ภาพหน้าจอเพื่อดูขนาดใหญ่ขึ้น

คำถามที่พบบ่อย

แอปนี้เหมือนกับ ReadFocus+ บน Android หรือไม่

เป็นแอปเดียวกันที่สร้างสำหรับ Windows และมีสองโหมดการอ่านเหมือนกัน แต่ซื้อแยกกันในแต่ละสโตร์ และไม่มีข้อมูลอะไรต้องซิงค์ เพราะ ReadFocus+ ไม่เก็บสิ่งที่คุณอ่านไว้เลย

ใช้กับแอปใดได้บ้าง

ใช้ได้กับทุกแอปที่อยู่บนหน้าจอ ทั้งเบราว์เซอร์ โปรแกรมอ่าน PDF และอีบุ๊ก เอกสาร โปรแกรมแก้ไขโค้ด งานวิจัย รวมถึงอีเมลหรือประวัติแชทยาว ๆ เพราะแถบช่วยอ่านถูกวาดทับบนหน้าจอ แอปด้านล่างจึงไม่ต้องรองรับอะไรเป็นพิเศษ

ใช้ฟรีได้ไหม

ได้ เวอร์ชันฟรีอ่านได้ครั้งละไม่เกิน 60 นาที และมีทั้งสองโหมดการอ่านกับธีม 2 แบบ ส่วน Pro เป็นการซื้อครั้งเดียวไม่ใช่การสมัครสมาชิก เพิ่มธีมพรีเมียม การตั้งค่าแถบโฟกัส (ความสูง ความทึบ ความมนของมุม) และการป้องกันหน้าจอดับ พร้อมยกเลิกการจำกัดเวลา เวอร์ชัน Windows ไม่มีโฆษณา
