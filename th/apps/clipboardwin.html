Clipboard+ for Windows

ตัวจัดการคลิปบอร์ดบนถาดระบบ Windows ที่ซิงก์กับมือถือ Android ของคุณผ่าน Google Drive ของคุณเอง

  • Windows · Microsoft Store
  • Windows 10+
ดูบน Microsoft Store → สอบถามและแจ้งปัญหา

ฟีเจอร์เด่น

  • ประจำอยู่บนถาดระบบและบันทึกข้อความกับรูปภาพทันทีที่คุณคัดลอก — ไม่ต้องคอยตรวจสอบอยู่เบื้องหลัง จึงเบา
  • ซิงก์มือถือกับพีซีสองทางผ่าน Google Drive ของคุณเอง
  • UI สไตล์ Android พร้อมธีมสว่าง/มืด แถบข้างกลุ่ม สนิปเป็ต และปักหมุด/คัดลอก/แก้ไข/ค้นหา
  • เลือกหลายรายการเพื่อย้าย ลบ และรวมเป็นชุด เรียงลำดับใหม่สุด/เก่าสุด และโปรแกรมดูรูปภาพขนาดเต็ม
  • หน้าต่างเลือกด่วนที่ตำแหน่งเคอร์เซอร์ด้วยปุ่มลัดส่วนกลาง พร้อมปุ่มลัดเปิดหน้าต่างและดึงข้อความที่เลือกไว้ในแอปอื่น และเริ่มทำงานพร้อม Windows
  • ส่งออก/นำเข้าที่เข้ากันได้กับรูปแบบสำรองข้อมูลของ Clipboard+ บน Android และส่งออก PDF

ภาพหน้าจอ

แตะที่ภาพหน้าจอเพื่อดูขนาดใหญ่ขึ้น

ภาพรวม

Clipboard+ for Windows คือตัวจัดการคลิปบอร์ดที่ประจำอยู่บนถาดระบบและบันทึกข้อความและรูปภาพที่คุณคัดลอกโดยอัตโนมัติ ทุกอย่างถูกบันทึกทันทีที่คัดลอก ดังนั้นแม้เผลอคัดลอกทับ คุณก็ยังเรียกเนื้อหาก่อนหน้ากลับมาวางได้ ปุ่มลัดส่วนกลางจะเปิดหน้าต่างเลือกด่วนขึ้นตรงตำแหน่งเคอร์เซอร์ เลือกคลิปด้วย Ctrl+1–9 แล้วกด Enter ก็วางลงในที่ที่คุณกำลังพิมพ์อยู่ได้เลยโดยไม่ต้องออกจากหน้าต่าง เมื่อใช้คู่กับแอป Clipboard+ บน Android สิ่งที่คุณคัดลอกบนมือถือก็นำไปวางบนพีซีได้ และสิ่งที่คัดลอกบนพีซีก็นำไปวางบนมือถือได้ เนื้อหาที่คัดลอกไม่ผ่านเซิร์ฟเวอร์ของ CodeDAC แต่ถูกเก็บไว้ใน Google Drive ของคุณเองเท่านั้น เนื้อหาที่บันทึกไว้จัดเป็นกลุ่มและสนิปเป็ตแล้วค้นหาได้

คำถามที่พบบ่อย

มันซิงก์กับแอป Clipboard+ บน Android ไหม?

ซิงก์ เพียงเปิดการซิงก์ด้วยบัญชี Google เดียวกันบนทั้งสองเครื่อง สิ่งที่คุณคัดลอกบนมือถือก็นำไปวางบนพีซีได้ และสิ่งที่คัดลอกบนพีซีก็นำไปวางบนมือถือได้ เนื้อหาไม่ผ่านเซิร์ฟเวอร์ของ CodeDAC แต่ส่งผ่าน Google Drive ของคุณเองเท่านั้น

ข้อมูลคลิปบอร์ดของฉันถูกเก็บไว้ที่ใด และปลอดภัยไหม?

ประวัติการคัดลอกโดยค่าเริ่มต้นจะอยู่ในพีซีของคุณเท่านั้น (โฟลเดอร์ %APPDATA%\ClipboardPlus) หากเปิดการซิงก์ ข้อมูลจะถูกเก็บไว้ในพื้นที่เฉพาะของแอปใน Google Drive ของคุณเองด้วย พื้นที่นี้ไม่ปรากฏบนหน้าจอ Drive และไม่มีอะไรเปิดได้นอกจาก Clipboard+ แอปใช้เพียงพื้นที่เฉพาะนี้ จึงเข้าถึงรูปภาพหรือเอกสารอื่นของคุณใน Drive ไม่ได้

ใช้ฟรีได้แค่ไหน และ Pro เพิ่มอะไรบ้าง

ประวัติคลิปบอร์ด สนิปเป็ตและกลุ่ม การค้นหา หน้าต่างเลือกด่วน รวมถึงธีมสว่างและมืด ใช้ได้ฟรีทั้งหมด ส่วน Pro เพิ่มการซิงก์ Google Drive การคัดลอกคลิปรูปภาพกลับไปยังคลิปบอร์ด การส่งออก PDF การนำเข้าไฟล์สำรอง กลุ่มไม่จำกัด และพื้นที่เก็บรูปภาพไม่จำกัด โดยรุ่นฟรีจำกัดพื้นที่เก็บรูปภาพไว้ที่ 50 MB
