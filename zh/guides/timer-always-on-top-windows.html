Windows 如何让计时器保持在其他窗口之上

更新于 2026-10-14

为演讲、专注时段或通话计时，时间一直在眼前会轻松很多。Windows 内置了一种方法，悬浮计时器应用则能做得更多。

方法一：时钟应用中的“Keep on top”

Windows 自带的时钟应用可以把计时器显示在一个保持在其他窗口之上的小窗口里：开始计时器，将其展开，然后选择“Keep on top”。它只适用于单个计时器，并显示在一个固定的小窗口中。

方法二：悬浮计时器卡片

FloatTimer+ for Windows（我们的应用）把计时器、计数器和秒表以小巧的马卡龙卡片悬浮在所有窗口之上。卡片从不获取焦点，所以点击卡片时，光标仍停在你刚才输入的位置。

  1. 从 Microsoft Store 安装 FloatTimer+；它常驻系统托盘。
  2. 创建计时器、计数器或秒表，并让它悬浮。
  3. 直接在卡片上开始、暂停和重置；可拖到任意位置或调整大小。
  4. 想腾出屏幕时，把它收成小气泡，或推到屏幕边缘。

免费版与 Pro

计时器、计数器和秒表想建多少建多少，没有广告。免费版一次悬浮两张卡片；Pro 为一次性买断，可同时悬浮任意多张，并增加重复计时器和自定义提醒。

常见问题

Windows 有始终置顶的计时器吗？

时钟应用的“Keep on top”可以把一个计时器显示在其他窗口之上的小窗口里。如果要同时使用多个计时器、计数器或秒表，请使用悬浮计时器应用。

悬浮计时器会妨碍我工作吗？

FloatTimer+ 的卡片从不抢走下层应用的焦点，你还可以把它们收成气泡或塞到屏幕边缘。
