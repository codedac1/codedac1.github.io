如何在 Windows 上查看剪贴板历史

更新于 2026-10-14

复制新内容后，之前的剪贴就没了——除非你保留了历史。Windows 10 和 11 都内置了剪贴板历史，而剪贴板管理应用可以保存得更久。

方法一：内置剪贴板历史（Win+V）

按 Win+V。第一次使用时，Windows 会提示你开启剪贴板历史（也可以在“设置 > 系统 > 剪贴板”中开启）。之后按 Win+V 就会显示最近的剪贴，点击某一条即可粘贴。

它很快捷，但有限制：最多保存 25 条，除固定的项目外，重启电脑后全部清空。不能搜索，也无法同步到手机。

方法二：什么都保留的剪贴板管理应用

Clipboard+ for Windows（我们的应用）常驻托盘，在你复制的那一刻保存文字和图片。历史会一直保留到你删除为止，可以搜索、整理成分组和常用短语，还能用热键调出。

  1. 从 Microsoft Store 安装 Clipboard+；它会在系统托盘中启动。
  2. 照常复制——每一条文字和图片剪贴都会自动保存。
  3. 按全局热键，在光标处打开快速选取窗口，用 Ctrl+1–9 选择一条剪贴，按 Enter 粘贴。
  4. 打开主窗口可以搜索、置顶、编辑，或把常用文字保存为常用短语。

在手机和电脑之间

搭配 Clipboard+ Android 应用使用，通过你自己的 Google Drive，手机上复制的内容可以在电脑上粘贴，反之亦然。剪贴板历史、常用短语、分组、搜索和快速选取窗口都免费；Pro 增加同步、无限图片存储空间和 PDF 导出。

常见问题

为什么重启后 Win+V 剪贴板历史是空的？

Windows 会在电脑重启时清空剪贴板历史，固定的项目除外。Clipboard+ 这样的剪贴板管理应用能在重启后保留你的历史。

Windows 剪贴板历史能保存多少条？

最多 25 条。复制新内容时，较早的条目会依次被挤掉。
