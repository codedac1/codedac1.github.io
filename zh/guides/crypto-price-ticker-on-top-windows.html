Windows 如何让实时加密货币行情条置顶在其他窗口之上

更新于 2026-10-14

开着交易所的标签页，每次想看价格都得切过去。悬浮行情条会让你关注的币种始终显示在所有窗口之上。

设置 FloatCrypto+ for Windows

FloatCrypto+ for Windows（我们的应用）把一条细长的行情条置于所有窗口之上，显示每个币种的代码和 24 小时涨跌幅。它从不抢走焦点，光标会留在你刚才输入的位置。

  1. 从 Microsoft Store 安装 FloatCrypto+，它会常驻在系统托盘中。
  2. 从 Binance 交易对中挑选币种，拖动排成你想要的顺序。
  3. 把行情条放到任意位置，调整透明度和字号——或把它收起成贴靠屏幕边缘的气泡。
  4. 在当前价格之上或之下设定目标，市场突破时就会收到桌面通知。双击币种即可查看图表。

须知

把鼠标悬停在托盘图标上可查看完整行情表，按 Ctrl+Alt+T 可隐藏行情条。价格来自 Binance 的公开市场数据，并会自动切换备用来源，最多可能延迟 30 秒；应用不进行交易，也不连接交易所账户，其中任何内容均不构成投资建议。

免费版可关注 2 个币种、设置 1 条提醒；Pro 为一次性购买，提供 10 个币种、无限提醒、10 秒刷新和更长周期的图表。没有广告。

本指南使用的应用

FloatCrypto+ for Windows

悬浮在 Windows 所有窗口之上的实时加密货币行情条，含价格提醒与图表。

在 Microsoft Store 查看 → 应用详情

常见问题

行情条会妨碍我工作吗？

不会。它从不抢走焦点；你可以调低不透明度、收起成气泡，或用 Ctrl+Alt+T 隐藏。

需要我的交易所账户吗？

不需要。它只读取公开市场数据，从不进行交易，也不保管资金。
