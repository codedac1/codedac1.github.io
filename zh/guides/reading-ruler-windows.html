如何在 Windows 上使用阅读标尺（适合阅读障碍和多动症人士）

更新于 2026-10-14

在显示器上读长篇内容很容易串行。阅读标尺会突出你正在读的那一行，或把屏幕其余部分调暗，让视线保持在正轨上。

方法一：Microsoft Edge 中的“行焦点”

Microsoft Edge 有沉浸式阅读器，为网页提供简洁的阅读视图。在它的阅读偏好设置中，“行焦点”一次突出显示一行、三行或五行。它只适用于能在沉浸式阅读器中打开的网页，不适用于 PDF、文档或其他应用。

方法二：覆盖任意应用的专注条

ReadFocus+ for Windows（我们的应用）会在你正在读的任何内容上铺一条专注条——网页、PDF、文档、代码。遮罩会压暗屏幕上下两侧，留出一条清晰的带；高亮则标出你正在读的那一行。专注条可点击穿透，你可以像以前一样在下面滚动和点击。

  1. 从 Microsoft Store 安装 ReadFocus+。
  2. 从悬浮面板或用键盘快捷键启动，并选择遮罩或高亮。
  3. 把专注条移到你读的那一行，或边读边用快捷键上下微调。
  4. 在面板中锁定、隐藏专注条，或把它移到另一台显示器。

免费版与 Pro

免费版包含两种模式和三款主题，每次最长 60 分钟。Pro 为一次性买断，取消时间限制，并增加高级主题、专注条高度和不透明度设置以及防止屏幕熄灭。没有广告。

本指南使用的应用

ReadFocus+ for Windows

可点击穿透的 Windows 专注条 — 遮罩与高亮，让视线始终停在正在读的那一行。

常见问题

Windows 有阅读标尺吗？

Edge 的沉浸式阅读器为网页提供“行焦点”。对于其他应用——PDF、Word、代码编辑器——需要 ReadFocus+ for Windows 这样的屏幕叠加层。

专注条会挡住我的点击吗？

不会。ReadFocus+ for Windows 可点击穿透：滚动、选择和点击都会传到下面的应用。
