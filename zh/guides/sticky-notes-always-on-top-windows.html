Windows 如何让便签始终置顶

更新于 2026-10-14

便签只有看得见才有用。在 Windows 上，桌面便签通常会被你正在用的浏览器、文档或表格挡住，只能翻找出来。让便签保持在最上层有两种方法。

方法一：用 PowerToys 置顶窗口

Microsoft PowerToys 是微软推出的一套免费实用工具，其中包含“Always On Top”。安装 PowerToys，开启“Always On Top”，点击你想保持在前面的窗口（例如便签窗口），然后按 Win+Ctrl+T。再按一次即可取消置顶。

这对几乎任何窗口都有效。缺点是置顶的仍是一个完整窗口：点击它就会获得焦点，而且不管你是否在看便签，它都占着同样大的地方。

方法二：本身就会悬浮的便签

FloatNote+ for Windows（我们的应用）把每条便签变成悬浮在所有窗口之上的小卡片。点击小卡片，它就在原地展开为便签；按 Esc 又收回去。小卡片从不抢走背后应用的焦点，所以光标会留在你刚才输入的位置。

  1. 从 Microsoft Store 安装 FloatNote+。
  2. 通过托盘图标或全局热键新建便签——它会以便签形式出现在屏幕上。
  3. 继续工作：便签始终在所有窗口之上。点顶部的箭头或按 Esc 把它收成小卡片。
  4. 小卡片可拖到任意位置，用颜色和富文本加以区分，还可以设置提醒，让便签在设定的时间弹出。

手机上也有你的便签

FloatNote+ for Windows 通过你自己的 Google Drive 与 FloatNote+ Android 应用同步，在电脑上写的便签也会出现在手机上。Windows 版的所有功能都免费。

FloatNote+ for Windows

悬浮于 Windows 任何窗口之上的便签，与 Android 版 FloatNote+ 同步。

常见问题

Windows 自带的便笺能保持在其他窗口之上吗？

在大多数设置下，单靠它自己做不到。你可以用 PowerToys 的“Always On Top”（Win+Ctrl+T）置顶任意窗口（包括便签窗口），或者使用本身就悬浮在其他窗口之上的便签应用。

悬浮便签会抢走我正在输入的焦点吗？

FloatNote+ 的小卡片不会。点击或拖动小卡片，光标仍留在你正在使用的应用里；只有展开后的便签会获得焦点，因为你要在里面输入。
