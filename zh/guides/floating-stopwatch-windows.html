Windows 电脑如何让秒表一直显示在屏幕上

更新于 2026-10-30

给速通、锻炼、任务或会议计时，秒表一直在眼前、而不是藏在当前窗口后面，会轻松很多。Windows 内置了一种方法，悬浮计时器应用则能做得更多。

方法一：时钟应用的秒表与“Keep on top”

Windows 自带的时钟应用有一个“秒表”选项卡。启动秒表并选择“Keep on top”，它就会显示在一个保持在其他窗口之上的小窗口里。

这种方法很快，也不需要额外安装。它只显示一个秒表，窗口大小固定。

方法二：以卡片悬浮的秒表

FloatTimer+ for Windows（我们的应用）把秒表、计时器和计数器以小巧的马卡龙卡片悬浮在所有窗口之上，每张卡片单独计时。卡片从不获取焦点，所以点击卡片时，光标仍停在你刚才输入或游戏的位置。

  1. 从 Microsoft Store 安装 FloatTimer+；它常驻系统托盘。
  2. 创建一个秒表，并让它悬浮。
  3. 直接用卡片上的 ▶/⏸/↻ 按钮开始、暂停和重新开始——无需打开应用。
  4. 把卡片拖到任意位置或调整大小；想腾出屏幕时，把它收成小气泡，或推到屏幕边缘。

游戏挡住了秒表怎么办

以独占全屏模式运行的游戏之上，任何窗口都无法置顶。在游戏设置中把显示模式改为无边框或窗口化，悬浮窗口——无论是时钟应用的窗口还是 FloatTimer+ 卡片——就会重新显示在游戏之上。

免费版与 Pro

秒表、计时器和计数器想建多少建多少，没有广告。免费版一次悬浮两张卡片；Pro 为一次性买断，可悬浮任意多张。

常见问题

Windows 有始终置顶的秒表吗？

有。时钟应用的秒表带有“Keep on top”，可以把一个秒表显示在其他窗口之上的小窗口里。如果要同时使用多个秒表、计时器或计数器，请使用悬浮计时器应用。

为什么一开游戏秒表就不见了？

游戏很可能处于独占全屏模式，这种模式会盖住所有其他窗口。请在游戏的显示设置中切换为无边框或窗口化模式。

可以同时运行多个秒表吗？

使用 FloatTimer+ 想建多少就建多少，每个单独计时。免费版一次显示两张悬浮卡片；Pro 可以悬浮更多。
