ReadFocus+ for Windows

常驻托盘的 Windows 阅读引导：阅读遮罩或行高亮帮你稳住视线，点击则原样穿透到下面的应用。

在 Microsoft Store 查看 → 联系我们

概览

ReadFocus+ for Windows 是安卓版 ReadFocus+ 的桌面版本。无论你在读网页、PDF、文档还是代码，它都会在上面铺一层安静的阅读引导，让你不容易串行。阅读遮罩会柔和地压暗屏幕上下两侧，只在中间留出一条明亮的带；行高亮则用淡色带标出你正在读的那一行。引导可点击穿透，下面的应用照常滚动、选择和点击；一个小巧的悬浮面板可以切换模式、移动或锁定色带、显示或隐藏，全程不用离开你正在读的内容。

也提供 Android 版本

ReadFocus+ 面向阅读障碍与多动症的阅读辅助，行高亮和阅读遮罩助你定位。 ›

主要功能

  • 两种阅读模式 — 阅读遮罩压暗明亮带以外的区域，行高亮标出你正在读的一行
  • 点击穿透 — 下面的应用照常滚动、选择、点击，不会拦截鼠标
  • 悬浮面板可切换模式、移动或锁定专注条并隐藏它，不需要时折叠成一行
  • 启动与停止、切换模式、显示与隐藏、锁定、上下微调专注条，全部支持键盘快捷键
  • 支持多显示器 — 面板移到哪块屏幕，阅读带就跟到哪块；平时常驻系统托盘
  • 无广告。Pro 为一次性买断：高级主题、专注条设置、防止屏幕熄灭、无时间限制

常见问题

它和安卓版 ReadFocus+ 是同一个应用吗？

是同一个应用的 Windows 版本，两种阅读模式完全相同。两者在各自商店分别购买，也没有需要同步的数据 — ReadFocus+ 不会保存你读的内容。

它能用在哪些应用上？

屏幕上的任何应用都可以：浏览器、PDF 和电子书阅读器、文档、代码编辑器、论文，以及很长的邮件或聊天记录。阅读引导画在屏幕之上，下面的应用无需做任何适配。

可以免费使用吗？

可以。免费版每次最长可读 60 分钟，包含两种阅读模式和 2 款主题。Pro 是一次性买断而非订阅，可解锁高级主题、专注条设置（高度、不透明度、圆角）和防止屏幕熄灭，并取消时间限制。Windows 版没有广告。
