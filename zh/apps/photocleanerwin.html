概览

PhotoCleaner+ for Windows 是安卓应用 PhotoCleaner+ 的桌面版。打开照片、截图或 PDF，或者用 Ctrl+V 粘贴、拖放到窗口中、在文件资源管理器中右键单击并选择“Clean with PhotoCleaner+”，检测就会自动开始。它会用方框标出电话号码、电子邮箱、卡号、IBAN、护照号码与机读区（MRZ），韩国居民登记号、外国人登记号、营业登记号、驾驶证号，韩文姓名、地址和车牌号，人脸（正面人脸最容易识别）、QR 码/条形码，以及你添加的始终遮盖的词。

自动检测只是起点，并不保证能找出全部内容：单击方框开启或关闭遮罩，拖动方框移动位置、拖动边缘调整大小，漏掉的地方自己拖动遮盖即可。文字识别使用 Windows 中已安装的文字识别语言，识别韩国文件需要安装韩语。导出时用不透明的实心遮盖，不是模糊，并可在结果界面保存（JPEG/PNG）、复制、分享、保存 PDF 或打印。保存的副本由像素重新编码，不含 EXIF、GPS 位置和拍摄时间；绝不修改原文件，也没有水印。一切都在本机运行，无需账户、不上传任何内容，也不保留最近打开的文件列表。

常见问题

这和安卓版 PhotoCleaner+ 是同一个应用吗？

是同一个应用的 Windows 版本：找出个人信息、确认方框、导出实心遮盖副本的流程相同。不过它使用 Windows 内置的文字和人脸识别，而不是手机上的识别引擎，所以结果相近但不完全相同。两个版本分别从各自的商店安装。

它能找出所有个人信息吗？

没有任何工具能做出这样的保证。自动检测只是起点：导出前请务必检查遮盖效果，漏掉的地方自己拖动遮盖。文字识别使用 Windows 中已安装的文字识别语言 —— 韩国证件号码、姓名和地址需要安装韩语，可在设置界面查看已安装的语言。

文件会被上传，或者原文件会被改动吗？

都不会。检测、遮盖和导出全部在你的电脑上运行，无需账户，不上传任何内容。遮盖在副本上进行，应用不允许覆盖保存到原文件；保存的副本经过重新编码，不含原文件的任何元数据。
