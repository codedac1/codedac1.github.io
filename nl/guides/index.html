Handleidingen voor Android en Windows

Stap-voor-stap antwoorden op alledaagse vragen: klembordgeschiedenis, notities en timers boven andere apps, automatisch starten na herstart, harder geluid, persoonlijke gegevens in screenshots verbergen en meer.

Android

Voor telefoons en tablets · Google Play

  • Klembordgeschiedenis bekijken op AndroidClipboard+
  • App automatisch openen na herstart op Android (zonder root)AutoStart+
  • Notitie boven andere apps houden op AndroidFloatNote+
  • Timer op je scherm houden terwijl je andere apps gebruikt op AndroidFloatTimer+
  • Persoonlijke gegevens in een screenshot verbergen voordat je hem deeltPhotoCleaner+
  • Leesliniaal bij dyslexie en ADHD op Android: je plek houden tijdens het lezenReadFocus+
  • Rekenmachine boven andere apps gebruiken op AndroidFloatCalc+
  • Cryptokoersen zien terwijl je andere apps gebruikt op AndroidFloatCrypto+
  • Je Android-telefoon luider makenVolumeBooster+

Windows

Voor Windows-pc's · Microsoft Store

  • Plaknotitie altijd bovenop houden in WindowsFloatNote+ for Windows
  • Klembordgeschiedenis bekijken in WindowsClipboard+ for Windows
  • Timer altijd bovenop andere vensters houden in WindowsFloatTimer+ for Windows
  • Leesliniaal gebruiken in Windows (bij dyslexie en ADHD)ReadFocus+ for Windows
  • Persoonlijke gegevens in screenshots en PDF’s verbergen in WindowsPhotoCleaner+ for Windows
  • Live cryptoticker altijd boven andere vensters houden in WindowsFloatCrypto+ for Windows
