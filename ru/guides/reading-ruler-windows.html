Как пользоваться линейкой для чтения в Windows (при дислексии и СДВГ)

Обновлено 2026-10-14

При чтении длинных страниц на мониторе строку легко потерять. Линейка для чтения подсвечивает строку, на которой вы находитесь, или затемняет остальную часть экрана, чтобы взгляд не сбивался.

Способ 1: «Line focus» в Microsoft Edge

В Microsoft Edge есть «Immersive Reader» — режим чистого чтения веб-страниц. В его настройках чтения функция «Line focus» подсвечивает одну, три или пять строк за раз. Она работает только на страницах, открытых в Immersive Reader, но не в PDF, документах или других приложениях.

Способ 2: полоса фокуса поверх любого приложения

ReadFocus+ for Windows (наше приложение) кладёт полосу фокуса поверх всего, что вы читаете: веб-страницы, PDF, документа, кода. «Маска» затемняет верх и низ экрана и оставляет светлую полосу; «Подсветка» отмечает строку, на которой вы находитесь. Полоса пропускает клики насквозь, поэтому вы прокручиваете и щёлкаете под ней как раньше.

  1. Установите ReadFocus+ из Microsoft Store.
  2. Запустите его с плавающей панели или сочетанием клавиш и выберите «Маску» или «Подсветку».
  3. Переместите полосу на свою строку или сдвигайте её вверх и вниз сочетаниями клавиш по ходу чтения.
  4. С панели можно зафиксировать полосу, скрыть её или перенести на другой монитор.

Бесплатно и Pro

Бесплатная версия включает оба режима и три темы, сеансами до 60 минут. Pro — разовая покупка: снимает ограничение по времени и добавляет премиум-темы, настройки высоты и непрозрачности полосы и «Не выключать экран». Рекламы нет.

Приложение из этой инструкции

ReadFocus+ for Windows

Кликопрозрачная полоса фокуса для Windows — Маска и Подсветка удерживают взгляд на строке.

Открыть в Microsoft Store → О приложении

Вопросы

Есть ли в Windows линейка для чтения?

В Immersive Reader браузера Edge есть Line focus для веб-страниц. Для других приложений — PDF, Word, редакторов кода — нужно экранное наложение, например ReadFocus+ for Windows.

Не будет ли полоса перехватывать мои клики?

Нет. ReadFocus+ for Windows пропускает клики насквозь: прокрутка, выделение и щелчки попадают в приложение под полосой.
