Как автоматически открывать приложение после перезагрузки Android (без root)

Обновлено 2026-10-14

В Android нет настройки, которая открывала бы приложение при включении телефона. Если после каждого перезапуска вы открываете одни и те же приложения — навигатор в машине, лаунчер на планшете-киоске, музыкальный плеер на автомагнитоле, — приложение для автозапуска сделает это за вас.

Почему это не происходит само

Начиная с Android 10 приложениям нельзя самостоятельно открывать экраны из фона. Поэтому приложению, которое должно открывать другие после перезагрузки, нужно разрешение «Поверх других приложений», и запускать их оно может только после того, как телефон впервые разблокирован.

Настройка с AutoStart+

AutoStart+ (наше приложение) открывает выбранные вами приложения после каждого перезапуска, как только вы разблокируете телефон. Root не нужен.

  1. Установите AutoStart+ из Google Play и откройте его.
  2. Нажмите «Добавить приложения» и выберите те, что должны открываться после перезагрузки. Перетаскивайте строки, чтобы задать, какое откроется первым.
  3. Когда появится запрос, разрешите «Поверх других приложений» — без этого Android заблокирует запуск.
  4. Нажмите «Проверить сейчас», чтобы увидеть, что произойдёт, не перезагружая телефон.
  5. Перезагрузите телефон и разблокируйте его: приложения откроются в заданном вами порядке.

Автомагнитолы и устройства, которые засыпают

Многие Android-автомагнитолы на самом деле не перезагружаются — когда машина заглушена, они засыпают. В AutoStart+ есть «Автомобильный режим», который снова открывает ваши приложения каждый раз, когда просыпается экран.

Приложение из этой инструкции

AutoStart+

Автозапуск ваших приложений при загрузке. Без root, настройте один раз.

Открыть в Google Play → О приложении

Вопросы

Нужен ли root для автозапуска приложений на Android?

Нет. AutoStart+ работает без root; ему нужно только разрешение «Поверх других приложений».

Почему приложения не открываются, пока я не разблокирую телефон?

Android не позволяет приложениям открывать другие, пока телефон не будет разблокирован хотя бы раз после перезагрузки. Ваши приложения откроются сразу после разблокировки.

Сколько приложений можно автоматически запускать бесплатно?

Бесплатная версия запускает 1 приложение при каждой загрузке. Pro запускает весь список по порядку.
