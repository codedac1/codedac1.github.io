Настоящая Политика конфиденциальности применяется к приложениям для Android и Windows, разработанным и предоставляемым CodeDAC («мы», «нас») (далее «Приложения»), а также к нашему веб-сайту codedac.com.

Кратко

  • Регистрация не требуется, и у CodeDAC нет серверов, которые получают или хранят ваши данные. Единственное исключение — запись о покупке, которую приложения для Windows отправляют после завершения покупки PRO (раздел 6).
  • По умолчанию данные приложений хранятся только на вашем устройстве.
  • Резервное копирование и синхронизация с Google Drive в Clipboard+ и FloatNote+ необязательны, а данные сохраняются только в вашем собственном Google Drive.
  • Рекламу в наших приложениях для Android показывает Google AdMob; там, где это требуется, сначала запрашивается согласие. В наших приложениях для Windows рекламы нет.
  • Вопросы: contact@codedac.com

1. Основной принцип

Вы можете пользоваться Приложениями без создания учётной записи и входа. У нас нет серверов, которые получают или хранят ваши данные, а данные, с которыми работают Приложения, по умолчанию хранятся и обрабатываются на вашем устройстве. Единственные исключения — необязательные функции, которые вы включаете сами (раздел 3), и внешние сервисы, на которые опираются Приложения (разделы 4–6); все они описаны ниже. Информация отправляется на наш сервер только в одном случае — это запись о покупке из приложений для Windows (раздел 6).

2. Информация, обрабатываемая на вашем устройстве

  • Данные, необходимые для работы Приложений (история буфера обмена, заметки, таймеры, настройки и т. п.), хранятся только на вашем устройстве и не передаются нам.
  • PhotoCleaner+ (Android) находит и скрывает персональную информацию на фотографиях и в PDF-файлах (распознавание текста, лиц и штрихкодов) с помощью встроенных в приложение моделей Google ML Kit на вашем устройстве. Фотографии и документы никогда не загружаются.
  • PhotoCleaner+ for Windows делает то же самое на вашем компьютере с помощью встроенного в Windows распознавания текста и лиц и входящего в приложение модуля чтения штрихкодов. Фотографии, PDF-файлы и вставленные изображения никогда не загружаются. Сохранённые копии заново кодируются из пикселей, поэтому не содержат метаданных оригинала (местоположение, время съёмки, сведения об устройстве). Приложение не хранит список открытых файлов, а временные файлы для отправки и печати удаляются при запуске и закрытии приложения. Слова, которые вы выбрали для постоянного скрытия, хранятся только в настройках приложения на вашем компьютере.
  • При удалении Приложения также удаляются данные приложения, хранящиеся на вашем устройстве.

3. Необязательная функция: резервное копирование и синхронизация с Google Drive

Clipboard+ (Android и Windows) и FloatNote+ (Android и Windows) предлагают функции Google Drive, позволяющие переносить данные между устройствами. По умолчанию эти функции отключены, и все остальные функции работают без них.

  • Вход через Google. Только когда вы включаете функцию, приложение просит вас войти с помощью учётной записи Google — исключительно для доступа к вашему собственному Google Drive.
  • Куда попадают ваши данные. При включённой синхронизации Clipboard+ сохраняет скопированные вами элементы, а FloatNote+ — ваши заметки в частную, доступную только приложению область вашего собственного Google Drive (скрытая папка appDataFolder). Данные попадают только в вашу учётную запись Google — они никогда не передаются в CodeDAC.
  • Ограниченный доступ. Синхронизация использует только область drive.appdata, которая видит лишь файлы, созданные приложением в этой скрытой области. Функция резервного копирования Clipboard+ для Android также использует область drive.file, которая аналогичным образом имеет доступ только к файлам резервных копий, созданным самим приложением. Ни одна из этих областей не имеет доступа к остальному содержимому вашего Google Drive.
  • Изображения. Изображения, прикреплённые к заметке FloatNote+, остаются на вашем устройстве; вместе с заметкой передаётся только ссылка на имя файла.
  • Отключение и удаление. Вы можете отключить эти функции или выйти из аккаунта в любое время. Удаление данных приложения или файлов резервных копий, хранящихся в вашем Google Drive, удаляет синхронизированные и резервные копии.

4. Информация, передаваемая через интернет

Некоторые функции получают информацию из интернета. Эти запросы не содержат ничего, что идентифицирует вас, однако, как и при любом интернет-запросе, удалённый сервер получает IP-адрес вашего устройства.

  • Курсы валют в FloatCalc+. При конвертации валют приложение получает курсы из публичного API курсов валют (Frankfurter).
  • Цены в FloatCrypto+. Цены и графики криптовалют загружаются из публичных API (CoinGecko, Binance).
  • ML Kit в PhotoCleaner+ (Android). Распознавание изображений выполняется на вашем устройстве, но Google ML Kit может отправлять в Google диагностическую информацию — сведения об устройстве (производитель, модель, версия ОС), сведения о приложении, а также показатели производительности и ошибок — для улучшения сервиса и устранения неполадок. Ваши фотографии и распознанное содержимое в неё не входят.
  • Microsoft Store в наших приложениях для Windows. Приложения для Windows взаимодействуют с Microsoft Store для проверки вашей лицензии PRO и покупок.

5. Реклама и согласие на рекламу

Наши бесплатные приложения для Android показывают рекламу Google AdMob. В наших приложениях для Windows рекламы нет.

  • Какие данные собираются. AdMob может собирать ваш рекламный идентификатор, приблизительное местоположение, определённое по IP-адресу, а также сведения об устройстве и использовании приложений для показа рекламы, измерения её эффективности и предотвращения мошенничества. Для этого приложения содержат разрешения, необходимые рекламному SDK (интернет, состояние сети, рекламный идентификатор), а некоторые приложения — также доступ к рекламным API Android (Privacy Sandbox). Как Google использует рекламные данные
  • Согласие на рекламу. В регионах, где требуется согласие, например в Европейском экономическом пространстве, Великобритании и Швейцарии, при первом запуске приложение запрашивает ваш выбор относительно персонализированной рекламы через экран согласия Google (User Messaging Platform). Большинство приложений позволяют изменить выбор в меню согласия на рекламу (параметры конфиденциальности) внутри приложения, а в любом приложении очистка его данных приводит к повторному запросу при следующем запуске.
  • Отключение персонализированной рекламы. Где бы вы ни находились, вы можете удалить или сбросить рекламный идентификатор либо отключить персонализацию рекламы в настройках устройства.
  • Удаление рекламы. Покупка PRO убирает рекламу.

6. Платежи

  • Android. Покупки PRO обрабатываются через Google Play Billing.
  • Windows. Покупки PRO обрабатываются через Microsoft Store.

Оплату обрабатывает соответствующий магазин; мы никогда не получаем номер вашей карты или другие платёжные данные. Приложения получают от магазина только статус покупки, необходимый для проверки вашего доступа к PRO.

Запись о покупке из приложений для Windows. Когда покупка PRO в PhotoCleaner+, ReadFocus+, FloatTimer+ или FloatCrypto+ для Windows завершена, приложение отправляет короткую запись на сервер CodeDAC (размещён в Google Cloud): идентификатор продукта, цену и валюту, показанные магазином, настройку страны или региона Windows, версию приложения и случайный номер, созданный для этой установки. Запись не содержит имени, адреса электронной почты, учётной записи Microsoft или сведений об устройстве. Мы используем её только для подсчёта продаж и чтобы одна и та же покупка не была учтена дважды; случайный номер хранится только в необратимо преобразованном (хешированном) виде. Как и при любом интернет-запросе, сервер получает ваш IP-адрес; журналы доступа к серверу автоматически удаляются через 30 дней.

7. Разрешения

Каждое приложение запрашивает только те разрешения, которые нужны для его функций, и использует их исключительно по заявленному назначению. Разрешения, запрашиваемые каждым приложением, перечислены выше в разделе К чему подключается каждое приложение.

  • Отображение поверх других приложений — показывает плавающий калькулятор, таймер, заметки, цены, инструмент для чтения или панель буфера обмена поверх экрана.
  • Уведомления — показывает состояние работающих функций и оповещения (завершение таймера, ценовые оповещения и т. п.).
  • Постоянная работа (служба переднего плана) — поддерживает работу таких функций, как плавающие окна или усиление громкости, после выхода из приложения.
  • Автозапуск при загрузке — перезапускает приложение или настроенные вами функции при включении устройства.
  • Игнорирование оптимизации батареи — не позволяет системе блокировать запуск при загрузке (AutoStart+).
  • Изменение настроек звука — применяет усиление громкости и эквалайзер (VolumeBooster+).
  • Рекламный идентификатор — используется для показа рекламы (раздел 5).

Базовые разрешения, такие как доступ к интернету, состояние сети и вибрация, предоставляются автоматически при установке и используются только для перечисленных выше функций. Приложения не запрашивают разрешения на доступ к микрофону, контактам, местоположению, камере или хранилищу.

8. Веб-сайт (codedac.com)

Наш веб-сайт использует Google Analytics для измерения посещаемости. Для посетителей из Европейского экономического пространства, Великобритании и Швейцарии режим согласия (Consent Mode) по умолчанию установлен на «отклонено», поэтому аналитические файлы cookie не сохраняются и отправляются только анонимные агрегированные сигналы; в остальных регионах для измерения посещений используются аналитические файлы cookie. Ни в одном из случаев мы не собираем рекламные идентификаторы, и на веб-сайте нет рекламы. Политика конфиденциальности Google

Вы можете отказаться от аналитики, заблокировав файлы cookie в браузере или установив браузерное дополнение для отключения Google Analytics. Веб-сайт использует локальное хранилище браузера (localStorage), чтобы запоминать выбранный вами язык и тему оформления (тёмный режим); эти значения никогда не отправляются на сервер.

9. Письма, которые вы нам отправляете

Если вы пишете нам по электронной почте, мы получаем ваш адрес электронной почты и содержание вашего письма (включая любые указанные вами сведения об устройстве или приложении). Мы используем эти данные только для того, чтобы ответить вам и обработать ваше обращение, и храним их только в течение срока, необходимого для этой цели.

10. Конфиденциальность детей

Для приложений, ориентированных на детей, мы соблюдаем Политику Google Play для семей и применимое законодательство. В контекстах, ориентированных на детей, мы не используем персонализированную рекламу и сознательно не собираем персональную информацию у детей.

11. Изменения в этой политике

Мы можем обновлять эту политику, чтобы отражать изменения в законодательстве или в Приложениях. В этом случае мы обновляем дату последнего обновления на этой странице и историю изменений ниже.
