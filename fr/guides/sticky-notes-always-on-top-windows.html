Garder un pense-bête toujours au premier plan sous Windows

Mis à jour 2026-10-14

Un pense-bête n’est utile que si vous le voyez. Sous Windows, les notes sur le bureau finissent généralement derrière le navigateur, le document ou le tableur sur lequel vous travaillez, et il faut aller les chercher. Il existe deux façons de garder une note au premier plan.

Option 1 : épingler une fenêtre avec PowerToys

Microsoft PowerToys, un ensemble gratuit d’utilitaires de Microsoft, inclut « Always On Top ». Installez PowerToys, activez « Always On Top », cliquez sur la fenêtre à garder devant — par exemple une fenêtre de notes — et appuyez sur Win+Ctrl+T. Appuyez de nouveau pour la désépingler.

Cela marche avec presque toutes les fenêtres. Le hic : une fenêtre épinglée reste une fenêtre complète. Elle prend le focus quand vous cliquez dessus, et elle occupe la même place que vous lisiez la note ou non.

Option 2 : des notes conçues pour flotter

FloatNote+ for Windows (notre appli) garde chaque note sous forme de petite pastille au-dessus de toutes les fenêtres. Cliquez sur la pastille, elle s’ouvre en carte sur place ; appuyez sur Esc, elle se replie. Les pastilles ne prennent jamais le focus à l’appli derrière elles : votre curseur reste là où vous tapiez.

  1. Installez FloatNote+ depuis le Microsoft Store.
  2. Créez une note depuis l’icône de la zone de notification ou avec un raccourci global : elle apparaît en carte par-dessus votre écran.
  3. Continuez à travailler : la note reste au-dessus de toutes les fenêtres. Appuyez sur Esc pour la réduire en pastille.
  4. Placez les pastilles où vous voulez, distinguez-les avec les couleurs et le texte enrichi, et réglez un rappel pour faire apparaître une note à une heure précise.

Vos notes aussi sur votre téléphone

FloatNote+ for Windows se synchronise avec l’appli Android FloatNote+ via votre propre Google Drive : une note écrite sur votre PC se retrouve sur votre téléphone. Toutes les fonctions de la version Windows sont gratuites.

L’appli de ce guide

FloatNote+ for Windows

Des pense-bêtes qui flottent au-dessus de n'importe quelle fenêtre Windows et se synchronisent avec l'appli Android FloatNote+.

Voir sur le Microsoft Store → Détails de l’appli

Questions

Les Pense-bêtes de Windows peuvent-ils rester au-dessus des autres fenêtres ?

Pas d’eux-mêmes dans la plupart des configurations. Vous pouvez épingler n’importe quelle fenêtre, y compris une fenêtre de notes, avec « Always On Top » de PowerToys (Win+Ctrl+T), ou utiliser une appli dont les notes flottent par conception au-dessus des autres fenêtres.

Une note flottante vole-t-elle le focus de ce que je tape ?

Pas les pastilles de FloatNote+. Cliquer ou faire glisser une pastille laisse votre curseur dans l’appli que vous utilisiez ; seule une carte ouverte prend le focus, puisque vous tapez dedans.
