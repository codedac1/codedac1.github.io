PhotoCleaner+ for Windows

写真・スクリーンショット・PDF の個人情報を見つけて枠で示し、ひとつずつ確認してから、メタデータのない塗りつぶしコピーを書き出します。処理はすべて PC 内です。

  • Windows · Microsoft Store
  • Windows 10+

主な機能

  • 電話番号・メールアドレス・カード番号・IBAN・パスポート番号と MRZ、韓国の身分証番号・氏名・住所・ナンバープレート、顔、QR コードを検出
  • 書き出す前にすべてのボックスを確認：クリックでオン・オフ、ドラッグで移動、端でサイズ変更、自分で塗りつぶし、元に戻す
  • 写真・スクリーンショット・PDF をドラッグ＆ドロップ、Ctrl+V で貼り付け、エクスプローラーの右クリック「Clean with PhotoCleaner+」で開く
  • ぼかしではない不透明な塗りつぶし、透かしなし — 保存（JPEG・PNG）・コピー・共有・PDFを保存・印刷
  • 保存コピーに EXIF・位置情報・メタデータなし、元のファイルは上書きしない
  • すべて PC 内で処理：アカウント不要、アップロードなし、最近使ったファイルの記録なし。ライト／ダークテーマ、21 言語

概要

PhotoCleaner+ for Windows は、Android アプリ PhotoCleaner+ のデスクトップ版です。写真・スクリーンショット・PDF を開くか、Ctrl+V で貼り付ける、ウィンドウにドラッグ＆ドロップする、エクスプローラーで右クリックして「Clean with PhotoCleaner+」を選ぶだけで、自動で検出が始まります。電話番号、メールアドレス、カード番号、IBAN、パスポート番号と MRZ、韓国の住民登録番号・外国人登録番号・事業者登録番号・運転免許証番号、韓国の氏名・住所・ナンバープレート、顔（正面の顔がもっとも検出しやすい）、QR コード・バーコード、そして登録した「常に隠す単語」を枠で示します。

自動検出は出発点であり、すべてを見つける保証ではありません。ボックスをクリックしてマスクをオン・オフし、ドラッグで移動、端をドラッグしてサイズを変え、見落としは自分でドラッグして隠してください。文字は Windows にインストールされている文字認識の言語で読み取るため、韓国の書類を読み取るには Windows に韓国語が必要です。書き出しでは、ぼかしではない不透明な塗りつぶしで隠し、結果画面から保存（JPEG・PNG）、コピー、共有、PDFを保存、印刷ができます。保存するコピーはピクセルから作り直すため EXIF・位置情報・撮影時刻は含まれず、元のファイルは変更も上書きもせず、透かしも入りません。すべて PC 内で動作し、アカウントもアップロードも不要で、最近使ったファイルの一覧も記録しません。

よくある質問

Android 版 PhotoCleaner+ と同じアプリですか？

同じアプリを Windows 向けに作ったもので、個人情報を見つけて枠で示し、確認してから塗りつぶしたコピーを書き出す流れも同じです。ただしスマートフォンの認識エンジンではなく Windows に内蔵された文字・顔認識を使うため、結果は似ていますが完全に同じではありません。インストールはそれぞれのストアから行います。

個人情報をすべて見つけてくれますか？

それを約束できるツールはありません。自動検出は出発点なので、書き出す前に必ずマスクを確認し、見落としは自分でドラッグして隠してください。文字は Windows にインストールされている文字認識の言語で読み取ります — 韓国の身分証番号・氏名・住所には韓国語が必要で、設定画面でインストール済みの言語を確認できます。

ファイルがアップロードされたり、元のファイルが変わったりしませんか？

どちらもありません。検出・マスク・書き出しはすべて、アカウントもアップロードもなしに PC 内で動作します。マスクはコピーに対して行い、元のファイルへの上書き保存はできません。保存するコピーは新しくエンコードされるため、元のファイルのメタデータは含まれません。
