FloatCrypto+ for Windows

ビットコイン・イーサリアム・アルトコインの相場を、すべてのウィンドウの上の細い1本のバーに。作業中もずっと視界の端に市場があり、フォーカスは決して奪いません。

  • Windows · Microsoft Store
  • Windows 10+
お問い合わせ・バグ報告 近日公開予定

主な機能

  • すべてのウィンドウの上に浮かぶリアルタイム価格ティッカー — 好きな場所へドラッグし、透明度と文字サイズを調整、画面の端のバブルに折りたたみ
  • フォーカスを奪わない — ティッカーは見えたまま、カーソルは作業中のアプリに残ります
  • 目標価格の上・下で知らせる価格アラート（1回または繰り返し）— コインの ⋮ メニューからコインが選択済みの状態ですぐ作成
  • Binance の数百の銘柄から選ぶウォッチリスト、ドラッグで並べ替え、期間の高値・安値・始値・変動率付きの1日・7日・30日チャート
  • 西洋式（上昇が緑・下落が赤）または東洋式（上昇が赤・下落が青）の配色、通知領域アイコンの価格一覧表
  • グローバルショートカット、通知領域に常駐、Windows 起動時に自動開始、ライト/ダークテーマ、21言語。広告なし・アカウント不要

概要

FloatCrypto+ for Windows は、Android 版 FloatCrypto+ のデスクトップ版です。ブラウザ、文書、ビデオ会議 — どのウィンドウの上にも細い価格ティッカーを置いておき、各コインのシンボルと24時間変動率を上昇・下落で色分けして表示します。タブを切り替える必要も、再読み込みする必要もありません。ティッカーは好きな場所へドラッグして透明度と文字サイズを調整でき、画面の端に寄り添う小さなバブルに折りたたむこともできます。入力中のアプリのフォーカスを奪うことはありません。通知領域のアイコンにマウスを重ねれば、ティッカーをオフにしていても価格の一覧表が表示されます。

現在価格より上か下に目標を決めておけば、相場がその線を越えた瞬間にデスクトップ通知でお知らせし、1回限りか繰り返しかを選べます。Binance で取引されている数百の銘柄から選んでドラッグで好きな順に並べ、コインをダブルクリックすると期間の高値・安値・始値・変動率付きのチャートが開きます。価格は Binance の公開マーケットデータから取得し、つながらないときは代替サーバーや CoinGecko へ自動で切り替わります。最大30秒遅れることがある参考情報であり、FloatCrypto+ は取引アプリではなく、アプリ内のいかなる内容も投資助言ではありません。

よくある質問

Android 版 FloatCrypto+ と同じアプリですか？

同じアプリを Windows 向けに作ったもので、浮かぶティッカー・価格アラート・ウォッチリスト・チャートもそのままです。2つはそれぞれのストアから入手する別々のアプリで、同期はしません — ウォッチリストとアラートは設定したデバイスに保存されます。

ティッカーが作業の邪魔になりませんか？

なりません。ティッカーはフォーカスを取らないフローティングのバーなので、クリックしてもドラッグしてもカーソルは入力していた場所のままです。透明度を下げる、文字を小さくする、画面の端に寄り添うバブルに折りたたむ、Ctrl+Alt+T で隠す — 隠していても、通知領域のアイコンにマウスを重ねればすべての価格が表示されます。

価格はどこから取得していますか？

Binance の公開マーケットデータから取得し、どこかにつながらないときは代替サーバーや CoinGecko へ自動で切り替わるので、ティッカーは止まりません。価格は最大30秒遅れることがある参考情報です。FloatCrypto+ は取引を行わず、取引所のアカウントにも接続せず、資産を預かることもありません。アプリ内のいかなる内容も投資助言ではありません。
