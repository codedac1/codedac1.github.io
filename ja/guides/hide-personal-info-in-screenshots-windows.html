Windowsでスクリーンショットや PDF の個人情報を隠す方法

更新日 2026-10-14

スクリーンショットやスキャンした書類には、電話番号、メールアドレス、カード番号や身分証番号、住所、顔が写っていることがよくあります。PCから送信や投稿をする前に、それらの情報を復元できないように覆っておきましょう。

方法1：Snipping Tool

Windows 11 の最近のバージョンの Snipping Tool では、「Text actions」からスクリーンショット内のメールアドレスや電話番号を隠せます。それ以外のものは上から描いて覆えます。ただし蛍光ペンは半透明なので使わず、各項目を完全に覆う不透明な線を使ってください。

方法2：PhotoCleaner+ for Windows

PhotoCleaner+ for Windows（私たちのアプリ）は、写真・スクリーンショット・PDFから個人情報らしい箇所を見つけます。電話番号、メールアドレス、カード番号、IBAN、パスポート番号、氏名、住所、ナンバープレート、顔、QRコードなどです。そのうえで不透明なマスクをかけた複製を書き出します。処理はすべてPCの中で行われ、何もアップロードされません。

  1. ファイルを開くか、Ctrl+V で貼り付けるか、ウィンドウにドラッグします。エクスプローラーで右クリックして「Clean with PhotoCleaner+」を選ぶこともできます。
  2. ボックスを確認します。クリックでオン・オフ、ドラッグで移動やサイズ変更ができ、見落としは自分で描いて覆います。
  3. マスクした複製を書き出します。保存、コピー、共有、PDFとして保存ができます。元のファイルが上書きされることはなく、保存した複製にはメタデータが含まれません。

無料版とPro

個人情報の検出は無料で回数制限がなく、書き出しは1日3ドキュメントまで無料です。Proは買い切りで、1日の上限をなくし、PDF書き出しと印刷を追加します。広告も透かしもありません。

よくある質問

個人情報をすべて見つけてくれますか？

それを約束できるツールはありません。検出は出発点にすぎないので、書き出す前に必ずボックスを確認し、見落としは自分で描いて覆ってください。

ファイルはアップロードされますか？

いいえ。検出・マスク・書き出しはすべてPCの中で行われ、アカウントは不要で、何もアップロードされません。
