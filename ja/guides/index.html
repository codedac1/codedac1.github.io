Android・Windows 使い方ガイド

クリップボード履歴の見方、ほかのアプリの上にメモやタイマーを表示する方法、再起動後のアプリ自動起動、音量を上げる方法、スクリーンショットの個人情報を隠す方法などを手順つきでまとめました。

Android

スマートフォン・タブレット向け · Google Play

  • Androidでクリップボードの履歴を見る方法Clipboard+
  • Androidで再起動後にアプリを自動で起動する方法（root不要）AutoStart+
  • Androidでメモを他のアプリの上に表示し続ける方法FloatNote+
  • Androidで他のアプリを使いながらタイマーを画面に表示する方法FloatTimer+
  • スクショを共有する前に個人情報を隠す方法PhotoCleaner+
  • Androidで使えるディスレクシア・ADHD向けリーディングルーラー：読んでいる行を見失わない方法ReadFocus+
  • Androidで他のアプリの上に電卓を表示して使う方法FloatCalc+
  • Androidで他のアプリを使いながら仮想通貨の価格を見る方法FloatCrypto+
  • Androidスマホの音を大きくする方法VolumeBooster+

Windows

Windows PC向け · Microsoft Store

  • Windowsで付箋を常に最前面に表示する方法FloatNote+ for Windows
  • Windowsでクリップボードの履歴を見る方法Clipboard+ for Windows
  • Windowsでタイマーを常に最前面に表示する方法FloatTimer+ for Windows
  • Windowsでリーディングルーラーを使う方法（ディスレクシア・ADHD向け）ReadFocus+ for Windows
  • Windowsでスクリーンショットや PDF の個人情報を隠す方法PhotoCleaner+ for Windows
  • Windowsで仮想通貨のリアルタイム価格を常に最前面に表示する方法FloatCrypto+ for Windows
