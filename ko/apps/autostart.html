AutoStart+

부팅하면 원하는 앱이 알아서 실행됩니다. 루트 불필요, 한 번만 설정하세요.

Google Play에서 보기 → 문의하기

개요

AutoStart+는 기기 부팅이 끝나는 순간 골라 둔 앱을 알아서 실행하는, 가장 단순한 안드로이드 자동 실행 관리자입니다. 루트도, 스크립트도, 매일 반복되는 탭도 필요 없습니다. 설치된 앱을 검색해 몇 초 만에 목록에 추가하고, 탭 한 번으로 켜고 끄고, 드래그해서 실행 순서를 정하세요. 확인하려고 재부팅할 필요도 없습니다 — 각 행의 ⋮ 메뉴가 그 앱을 바로 열고, 부팅 직후에는 무엇이 실행됐는지 짧게 알려 주며 나머지도 한 번의 탭으로 실행합니다. 무료 버전은 앱 1개를 자동 실행하고, PRO는 한도를 풀어 목록 전체를 순서대로 실행합니다. 결제가 부담스럽다면 짧은 광고를 보고 24시간 동안 한도를 해제할 수 있습니다.

주요 기능

  • 부팅이 끝나는 순간 골라 둔 앱을 자동 실행 — 루트도 커스텀 롬도 필요 없음
  • 설치된 모든 앱을 검색해 몇 초 만에 추가하고 탭 한 번으로 켜고 끄기
  • 드래그로 매 부팅마다 어떤 앱이 먼저 실행될지 순서 지정
  • 각 행의 ⋮ 메뉴에서 '지금 실행' — 재부팅하지 않고 목록 확인
  • 부팅 오버레이 배너로 잠금화면에서도 목록 전체를 한 번의 탭으로 실행 (PRO)
  • 무료는 앱 1개, PRO는 한도 해제 — 짧은 광고로 24시간 해제도 가능

자주 묻는 질문

부팅 후 앱이 실행되지 않아요.

샤오미·오포·비보·화웨이는 기본적으로 백그라운드 자동 시작을 막습니다. AutoStart+가 기기를 알아보고 해당 폰의 보안 설정 안에 있는 '자동 시작' 화면으로 바로 데려다줍니다. 거기서 허용하면 부팅 자동 실행이 동작하며, 배터리 최적화에서 제외해 두면 더 안정적입니다.

몇 개의 앱을 자동 실행할 수 있나요?

무료 버전은 부팅마다 1개를 실행합니다. PRO는 한도를 풀어 목록 전체를 정해 둔 순서대로 실행합니다. 결제가 부담스럽다면 짧은 광고를 보고 24시간 동안 한도를 해제할 수 있습니다.

배터리 소모가 늘어나나요?

AutoStart+는 부팅 시 단 한 번만 동작하는 상시 실행 앱이 아니므로 배터리에 거의 영향이 없습니다.
