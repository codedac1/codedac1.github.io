FloatNote+ for Windows

지금 쓰고 있는 창 위에 그대로 떠 있는 스티커 메모. 창을 옮기지 않고 적을 수 있고, 쓰던 앱의 포커스를 빼앗지 않습니다.

  • Windows · Microsoft Store
  • Windows 10+
Microsoft Store에서 보기 → 문의·버그 신고

주요 기능

  • 모든 창 위에 떠 있는 스티커 메모 — 칩을 누르면 그 자리에서 편집 가능한 카드로 펼쳐지고 Esc로 다시 접힙니다
  • 포커스를 빼앗지 않음 — 칩을 끌거나 눌러도 커서는 치고 있던 앱에 그대로 있습니다
  • 저장 버튼 없음: 친 글은 알아서 저장되고, 보관함 창이 검색·고정·관리를 맡습니다
  • 서식 — 굵게·기울임·밑줄·취소선, 글자 색과 크기 — 여기에 파스텔 메모 7색과 본문 이미지까지
  • 내 구글 드라이브를 통한 폰↔PC 양방향 동기화 — 안드로이드 앱과 같은 앱 전용 폴더를 쓰고, CodeDAC 서버는 거치지 않습니다
  • 전역 단축키, 시스템 트레이 상주, 라이트·다크 테마, 로그온 자동 실행, 21개 언어. 광고 없음, Pro는 일회성 구매

개요

FloatNote+ for Windows는 안드로이드 FloatNote+ 앱의 데스크톱 버전입니다. 메모 하나하나가 브라우저·편집기·스프레드시트 위에 작은 칩으로 떠 있고, 누르면 그 자리에서 카드로 펼쳐져 바로 읽고 고칠 수 있으며 Esc로 다시 칩으로 접힙니다.

칩은 뒤에 있는 앱의 포커스를 절대 빼앗지 않으므로 치고 있던 글은 그대로 남고, 저장 버튼도 없습니다 — 친 글은 알아서 저장됩니다. 파스텔 7색과 서식, 본문 이미지로 메모를 구분하고, 보관함 창이 검색·고정·관리를 맡습니다. 선택 기능인 동기화는 본인 구글 드라이브의 앱 전용 폴더를 거치며, 안드로이드 앱이 쓰는 바로 그 폴더입니다.

자주 묻는 질문

안드로이드 FloatNote+와 같은 앱인가요?

같은 앱을 Windows용으로 만든 것으로, 칩과 카드도 동일합니다. 구매는 각 스토어에서 따로 하지만, 두 앱의 설정에서 각각 Google Drive에 같은 계정으로 로그인하고 자동 동기화를 켜면 PC에서 적은 메모가 폰에, 폰에서 적은 메모가 PC에 옵니다. 메모는 CodeDAC 서버를 거치지 않고 사용자 본인의 구글 드라이브에만 저장됩니다. 메모 글과 첨부 이미지가 함께 동기화됩니다.

아래에 있는 앱을 방해하지는 않나요?

방해하지 않습니다. 칩은 포커스를 가져가지 않는 플로팅 창이라, 누르거나 끌어도 커서는 치고 있던 자리에 그대로 있습니다. 칩을 누르면 카드로 펼쳐지고, Esc를 누르거나 바깥을 클릭하면 저장된 채로 다시 접힙니다.

무료로 쓸 수 있나요?

네. 메모를 쓰고 보관하는 것은 무료로 무제한이며 Windows 판에는 광고가 없습니다. 무료 버전은 화면에 한 번에 한 개를 띄우며, 일곱 색은 모두 쓸 수 있습니다. Pro는 구독이 아닌 일회성 구매로, 플로팅 메모 무제한, 본문 이미지, 메모 투명도 조절, 구글 드라이브 동기화, 내보내기·가져오기를 더합니다.
