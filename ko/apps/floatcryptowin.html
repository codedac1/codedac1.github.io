FloatCrypto+ for Windows

비트코인 · 이더리움 · 알트코인 시세를 모든 창 위의 얇은 한 줄로 — 일하는 내내 시장이 눈 한쪽에 있고, 포커스는 절대 뺏지 않습니다.

  • Windows · Microsoft Store
  • Windows 10+

  • 모든 창 위에 떠 있는 실시간 시세 티커 — 원하는 곳으로 끌어다 두고 투명도 · 글자 크기 조절, 화면 가장자리 버블로 접기
  • 포커스를 뺏지 않습니다 — 티커는 계속 보이고 커서는 작업 중인 앱에 그대로

  • 바이낸스 수백 개 코인에서 고르는 관심 목록, 끌어서 순서 변경, 1일 · 7일 · 30일 차트와 기간 고가 · 저가 · 시가 · 변동률
  • 서양식(상승 초록 · 하락 빨강) · 동양식(상승 빨강 · 하락 파랑) 색상, 트레이 아이콘의 전체 시세 표
  • 전역 단축키, 시스템 트레이, Windows 시작 시 실행, 라이트 · 다크 테마, 21개 언어. 광고 없음, 계정 없음

개요

FloatCrypto+ for Windows 는 안드로이드 FloatCrypto+ 의 데스크톱판입니다. 브라우저, 문서, 화상 회의 — 어떤 창 위에든 얇은 시세 티커를 띄워 두고, 코인마다 심볼과 24시간 변동률을 오르내림에 따라 색으로 보여 줍니다. 탭을 오갈 필요도, 새로고침할 필요도 없습니다. 티커는 원하는 곳으로 끌어다 두고 투명도와 글자 크기를 맞추거나, 화면 가장자리에 반쯤 숨는 작은 버블로 접을 수 있으며, 지금 입력 중인 앱의 포커스를 절대 뺏지 않습니다. 트레이 아이콘에 마우스를 올리면 티커를 꺼 둔 상태에서도 전체 시세 표가 나옵니다.

현재가보다 위나 아래로 목표가를 정해 두면 시세가 그 값을 넘는 순간 데스크톱 알림을 보내고, 한 번만 또는 반복으로 설정할 수 있습니다. 바이낸스에서 거래되는 수백 개 코인 중에서 골라 원하는 순서로 끌어 정렬하고, 코인을 두 번 클릭하면 기간 고가 · 저가 · 시가 · 변동률이 담긴 차트가 열립니다. 시세는 바이낸스 공개 시장 데이터를 쓰고 막히면 예비 서버와 CoinGecko 로 자동 전환합니다. 최대 30초 지연될 수 있는 참고용 데이터이며, FloatCrypto+ 는 거래 앱이 아니고 어떤 내용도 투자 자문이 아닙니다.

자주 묻는 질문

안드로이드의 FloatCrypto+ 와 같은 앱인가요?

같은 앱을 Windows 용으로 만든 것으로, 떠 있는 티커 · 가격 알림 · 관심 목록 · 차트가 그대로 있습니다. 두 앱은 각자의 스토어에서 받는 별개 앱이며 동기화되지 않습니다 — 관심 목록과 알림은 설정한 기기에 저장됩니다.

티커가 작업을 방해하지 않나요?

아니요. 티커는 포커스를 가져가지 않는 떠 있는 띠라서, 클릭하거나 끌어도 커서는 입력하던 자리에 그대로 있습니다. 투명도를 낮추거나 글자를 줄이거나, 화면 가장자리에 반쯤 숨는 버블로 접거나, Ctrl+Alt+T 로 숨길 수 있습니다. 숨겨 두어도 트레이 아이콘에 마우스를 올리면 모든 시세가 보입니다.

시세는 어디서 가져오나요?

바이낸스의 공개 시장 데이터를 쓰고, 한쪽이 막히면 예비 서버와 CoinGecko 로 자동 전환해 티커가 멈추지 않습니다. 시세는 최대 30초 지연될 수 있는 참고용입니다. FloatCrypto+ 는 거래를 하거나 거래소 계정에 연결하거나 자산을 보관하지 않으며, 어떤 내용도 투자 자문이 아닙니다.
