Clipboard+ for Windows

안드로이드와 클립보드를 내 구글 드라이브로 잇는 Windows 트레이 클립보드 매니저

  • Windows · Microsoft Store
  • Windows 10+
Microsoft Store에서 보기 → 문의·버그 신고

주요 기능

  • 트레이에 상주하며 복사하는 즉시 텍스트·이미지를 자동 저장 — 백그라운드에서 계속 들여다보지 않아 가볍습니다
  • 내 구글 드라이브를 통한 폰↔PC 양방향 동기화
  • 안드로이드 스타일 UI — 라이트/다크 테마, 그룹 사이드바, 스니펫, 핀·복사·편집·검색
  • 다중 선택 일괄 이동/삭제/병합, 최신·오래된순 정렬, 이미지 원본 뷰어
  • 커서 자리에 뜨는 전역 단축키 빠른 선택 팝업, 창 열기와 타 앱 선택 텍스트 캡처 단축키, Windows 자동 실행
  • 안드로이드 Clipboard+ 백업 포맷 호환 내보내기/가져오기, PDF 내보내기

스크린샷

개요

Clipboard+ for Windows는 시스템 트레이에 상주하며 복사한 텍스트와 이미지를 자동으로 저장해 주는 클립보드 매니저입니다. 복사하는 순간 바로 기록되므로 실수로 덮어써도 지난 내용을 다시 꺼내 붙여넣을 수 있습니다. 전역 단축키를 누르면 커서가 있는 자리에 빠른 선택 팝업이 떠서, Ctrl+1~9로 클립을 고르고 Enter를 누르면 창을 떠나지 않고 그대로 붙여넣습니다.

안드로이드 Clipboard+ 앱을 함께 쓰면 폰에서 복사한 내용을 PC에서, PC에서 복사한 내용을 폰에서 그대로 붙여넣을 수 있습니다. 이때 복사한 내용은 CodeDAC 서버를 거치지 않고 사용자 본인의 구글 드라이브에만 저장됩니다. 저장된 기록은 그룹과 스니펫으로 정리하고 검색할 수 있습니다.

자주 묻는 질문

안드로이드 Clipboard+ 앱과 동기화되나요?

네. 두 기기에서 같은 구글 계정으로 동기화를 켜면, 폰에서 복사한 내용을 PC에서 붙여넣고 PC에서 복사한 내용을 폰에서 붙여넣을 수 있습니다. 내용은 CodeDAC 서버를 거치지 않고 사용자 본인의 구글 드라이브로만 오갑니다.

제 클립보드 데이터는 어디에 저장되나요? 안전한가요?

복사 기록은 기본적으로 내 PC 안에만 저장됩니다(%APPDATA%\ClipboardPlus 폴더). 동기화를 켜면 내 구글 드라이브의 앱 전용 공간에도 저장되는데, 이 공간은 드라이브 화면에 보이지 않고 Clipboard+ 외에는 열 수 없습니다. 앱은 이 전용 공간만 사용하므로 드라이브에 있는 다른 사진이나 문서에는 접근할 수 없습니다.

무료로 어디까지 쓸 수 있고, Pro는 무엇이 열리나요?

클립보드 기록, 스니펫과 그룹, 검색, 빠른 선택 팝업, 라이트·다크 테마는 모두 무료입니다. Pro로 업그레이드하면 Google Drive 동기화, 이미지 클립 복사, PDF 내보내기, 백업 가져오기, 무제한 그룹, 무제한 이미지 저장 용량이 열립니다. 무료 이미지 저장 용량은 50MB까지입니다.
