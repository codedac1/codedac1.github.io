CodeDAC = Code 기반의 Development And Consulting

  2. 02신뢰

    꼭 필요한 권한만 요청하고 광고는 최소로 줄이며, 사용자의 데이터를 존중합니다.

  3. 03꾸준함

    출시는 시작일 뿐입니다. 리뷰와 메일로 들려주신 의견이 다음 업데이트가 됩니다.

BUILD WITH US

CodeDAC와 함께 만드는 두 가지 방법

직접 만들고 싶은 제품이 있나요, 아니면 앱이 대신 해결해 줬으면 하는 불편이 있나요? 맞는 쪽을 골라 주세요. 둘 다 짧은 양식 하나로 시작합니다.

어느 쪽인지 헷갈리신다면: 앱을 직접 소유하고 비용을 낼 생각이면 '프로젝트 의뢰', 그런 앱이 있기만 하면 된다면 '앱 아이디어 제보'(무료)를 골라 주세요.

유료

프로젝트 의뢰

고객님의 제품을 만드는 유료 개발이며, 결과물은 고객님 소유입니다.

이런 일을 합니다

  • 앱 개발Android·iOS·Windows 데스크톱 및 크로스플랫폼 앱을 기획부터 출시·운영까지 개발합니다.
  • 웹 개발반응형 웹사이트, 웹 애플리케이션, 관리자 시스템을 구축합니다.
  • 기술 컨설팅아키텍처 설계, 기술 스택 선정, 코드 리뷰 등 기술 의사결정을 함께합니다.
  • 유지보수 · 운영안정적인 운영, 성능 개선, 배포 자동화(CI/CD)로 서비스를 지속 관리합니다.
