안드로이드·윈도우 사용 가이드

클립보드 기록 보기, 다른 앱 위에 메모·타이머 띄우기, 재부팅 후 앱 자동 실행, 소리 키우기, 스크린샷 개인정보 가리기 등 자주 묻는 방법을 단계별로 정리했습니다.

Android

휴대폰·태블릿용 · Google Play

  • 안드로이드 클립보드 기록 보는 법Clipboard+
  • 안드로이드 재부팅 후 앱 자동 실행하는 법 (루팅 없이)AutoStart+
  • 안드로이드에서 메모를 다른 앱 위에 띄워 두는 법FloatNote+
  • 안드로이드에서 다른 앱을 쓰며 타이머 띄워 두는 법FloatTimer+
  • 캡처를 공유하기 전에 개인정보 가리는 법PhotoCleaner+
  • 난독증·ADHD를 위한 안드로이드 리딩 룰러: 읽던 줄 놓치지 않기ReadFocus+
  • 안드로이드에서 다른 앱 위에 계산기 띄우는 법FloatCalc+
  • 안드로이드에서 다른 앱을 쓰며 코인 시세 보는 법FloatCrypto+
  • 안드로이드 폰 소리를 더 크게 하는 법VolumeBooster+

Windows

Windows PC용 · Microsoft Store

  • 윈도우에서 스티커 메모를 항상 위에 두는 법FloatNote+ for Windows
  • 윈도우 클립보드 기록 보는 법Clipboard+ for Windows
  • 윈도우에서 타이머를 다른 창 위에 띄워 두는 법FloatTimer+ for Windows
  • 윈도우에서 리딩 룰러 쓰는 법 (난독증·ADHD)ReadFocus+ for Windows
  • 윈도우에서 캡처·PDF의 개인정보 가리는 법PhotoCleaner+ for Windows
  • 윈도우에서 코인 시세를 다른 창 위에 띄워 두는 법FloatCrypto+ for Windows
