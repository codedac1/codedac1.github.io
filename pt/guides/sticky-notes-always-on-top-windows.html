Como deixar uma nota adesiva sempre visível no Windows

Atualizado 2026-10-14

Uma nota adesiva só é útil se você consegue vê-la. No Windows, as notas na área de trabalho costumam ficar atrás do navegador, do documento ou da planilha em que você está trabalhando, e você precisa ir atrás delas. Há duas formas de manter uma nota por cima.

Opção 1: fixar uma janela com o PowerToys

O Microsoft PowerToys, um conjunto gratuito de utilitários da Microsoft, inclui o “Always On Top”. Instale o PowerToys, ative o “Always On Top”, clique na janela que quer manter na frente — por exemplo, uma janela de notas — e pressione Win+Ctrl+T. Pressione de novo para desafixar.

Funciona com quase qualquer janela. O problema é que uma janela fixada é uma janela inteira: ela pega o foco quando você clica nela e ocupa o mesmo espaço, esteja você lendo a nota ou não.

Opção 2: notas que já flutuam por padrão

O FloatNote+ for Windows (nosso app) mantém cada nota como um chip pequeno acima de todas as janelas. Clique no chip e ele abre ali mesmo como cartão; pressione Esc e ele recolhe de novo. Os chips nunca tiram o foco do app atrás deles, então o cursor fica onde você estava digitando.

  1. Instale o FloatNote+ pela Microsoft Store.
  2. Crie uma nota pelo ícone na bandeja ou com um atalho global — ela aparece como um cartão sobre a tela.
  3. Continue trabalhando: a nota fica acima de todas as janelas. Pressione Esc para recolhê-la em um chip.
  4. Arraste os chips para onde quiser, use cores e texto rico para diferenciá-los e defina um lembrete para fazer uma nota aparecer em um horário definido.

Suas notas também no celular

O FloatNote+ for Windows sincroniza com o app FloatNote+ para Android pelo seu próprio Google Drive, então uma nota que você escreve no PC aparece no celular. Todos os recursos da versão para Windows são gratuitos.

Perguntas

O Sticky Notes do Windows pode ficar acima de outras janelas?

Na maioria das configurações, não sozinho. Você pode fixar qualquer janela, inclusive uma janela de notas, com o “Always On Top” do PowerToys (Win+Ctrl+T), ou usar um app cujas notas já flutuam acima de outras janelas por padrão.

Uma nota flutuante tira o foco do que estou digitando?

Os chips do FloatNote+ não. Clicar em um chip ou arrastá-lo deixa o cursor no app que você estava usando; só um cartão aberto pega o foco, porque você digita nele.
